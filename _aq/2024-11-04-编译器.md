# 1. 简介

Jekyll 网站上使用 Liquid 模板语言非常直接，因为 Jekyll 本身就是基于 Ruby 开发的一个静态站点生成器，而 Liquid 是 Ruby 的一个开源模板引擎。  
使 Jekyll 识别并处理包含 Liquid 代码的文件，文件名应该以 .html、.md 或 .liquid 结尾

# 2. 基本语法

## 2.1. 变量

变量：使用双大括号 `{{ }}` 包围变量名来输出变量值。例如：`{{ page.title }} `会输出页面的标题。

## 2.2. 条件语句

使用 `{% if %}`、`{% else %}` 和` {% endif %}`。

## 2.3. 循环语句

使用` {% for %}` 和 `{% endfor %}` 来遍历数组或集合。

```
{% for post in site.posts limit:5 %}  #限制显示最近5篇文章
  <h2>{{ post.title }}</h2>
  <p>{{ post.excerpt }}</p>
{% endfor %}
```

## 2.4. 内置对象

site、page、post 和 layout

### 2.4.1 site 变量包含了有关整个站点的信息

- site.title： 站点的标题。
- site.description： 站点的描述。
- site.url： 站点的 URL。
- site.baseurl： 站点的基础 URL（如果你在子路径上部署站点）。
- site.time： 站点构建的时间。
- site.pages： 站点中的所有页面。
- site.posts： 站点中的所有帖子。
- site.categories： 站点中的所有分类。
- site.tags： 站点中的所有标签。
- site.data： 站点的数据文件（位于 \_data 目录）。
- site.static_files： 站点中的所有静态文件。
- site.html_pages： 站点中的所有 HTML 页面。
- site.collections： 站点中的所有集合。

### 2.4.2 page 变量包含了当前页面的信息

- page.title： 页面的标题。
- page.content： 页面的内容。
- page.url： 页面的 URL。
- page.date： 页面的日期（仅适用于帖子）。
- page.categories： 页面的分类（仅适用于帖子）。
- page.tags： 页面的标签（仅适用于帖子）。
- page.author： 页面的作者。
- page.layout： 页面使用的布局。
- page.next： 下一个页面的信息。
- page.previous： 上一个页面的信息。

### 2.4.3 post 变量 量包含了当前帖子的信息

- post.title： 帖子的标题。
- post.content： 帖子的内容。
- post.url： 帖子的 URL。
- post.date： 帖子的发布日期。
- post.categories： 帖子的分类。
- post.tags： 帖子的标签。
- post.author： 帖子的作者。
- post.next： 下一个帖子的信息。
- post.previous： 上一个帖子的信息。

### 2.4.4 paginator 变量 在分页页面中可用，包含了分页的相关信息

- paginator.page： 当前页码。
- paginator.per_page： 每页显示的文章数量。
- paginator.posts： 当前页的文章列表。
- paginator.total_posts： 总文章数。
- paginator.total_pages： 总页数。
- paginator.previous_page： 上一页的页码。
- paginator.previous_page_path： 上一页的 URL。
- paginator.next_page： 下一页的页码。
- paginator.next_page_path： 下一页的 URL。

### 2.4.5 include 变量

include 变量在包含文件中可用，包含了传递给包含文件的参数

```Liquid
{% include header.html title="My Title" %}
```

```
//header.html 可以使用include来接收参数
<h1>{{ include.title }}</h1>
```

分组 它将所有文章按月份和年份分组

```
{% assign postsByYearMonth = site.posts | group_by_exp: "post", "post.date | date: '%B %Y'" %}
{% for yearMonth in postsByYearMonth %}
  <h3>{{ yearMonth.name }}</h3>
  <ul>
    {% for post in yearMonth.items %}
      <li><a href="{{ post.url }}">{{ post.title }}</a></li>
    {% endfor %}
  </ul>
{% endfor %}
```

## 2.5 DATA

你可以在 `_data` 目录中创建数据文件，并在模板中使用它们。例如，如果你有一个 \_data/members.yml 文件：

```yml
- name: John Doe
  role: Developer
- name: Jane Smith
  role: Designer
```

可以在模板中这样访问这些数据

```
<ul>
  {% for member in site.data.members %}
    <li>{{ member.name }} - {{ member.role }}</li>
  {% endfor %}
</ul>
```
