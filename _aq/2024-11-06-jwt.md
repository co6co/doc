# 1. Json Web Token
`JWT`：`Json Web Token`。它是一种在Web中，使用Json来进行Token授权的方案。

token是如何解决信任问题:
- token是不是来自我信任的机构颁发
  一般都是通过加密算法来建立信任，颁发时使用密钥进行加密，如果能够对加密[对称加密或非对称]内容进行正常解密说明token来自信任方
- token中的信息是否被篡改	
  将签名部分使用秘钥进行解密，如果可以正常解开，说明令牌来自信任方颁发，
  将解密后的内容与JWT的头部和有效载荷的base64编码内容对比是否一致，如果一致，说明令牌未被篡改

# 2. JWT 格式说明

|名称|作用|备注|
|--|--|--|
|Header[头]| `{ "alg": "HS256", "typ": "JWT"}`|base64 编码|
|Payload [有效载荷]|使用base64进行序列化，任何人都可以读到，所以不要包含敏感信息|base64 编码|
|Signature [签名]|防止抵赖-防止篡改，一旦头和有效载荷有内容被篡改，则生成签名部分必将与原内容不同|HMACSHA256( header+'.'+payload,密钥)|

## 2.1 Signature 计算方法和验证方法：
```
=HMACSHA256(base64UrlEncode(header) + "." + base64UrlEncode(payload), secret)
```
Json Web Token加密后格式为:
`base64UrlEncode(header).base64UrlEncode(payload).Signature`
