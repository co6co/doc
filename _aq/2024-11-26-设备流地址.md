# 1. 海康设备

```
// 海康录像机
rtsp://admin:123456@192.168.1.64:554/Streaming/tracks/101?starttime=20231213T170000z&endtime=20231213T190000z
// 一体机设备
rtsp://{userName}:{pwd}@{ip}:554/Streaming/Channels/1
rtsp://{userName}:{pwd}@{ip}:554/Streaming/Channels/2
//常见枪机、球机设备
rtsp://{userName}:{pwd}@{ip}:554/Streaming/Channels/1
```

# 3. 大华

```
# rtsp://192.168.2.235:554/cam/realmonitor?channel=1&subtype=0&unicast=true&proto=Onvif
# <channel>是摄像头通道编号，这里是 “1”，表示第一通道。
# <subtype>表示子流类型，“0” 表示主码流，“1” 表示子码流，此处 “0” 代表主码流。
rtsp://{userName}:{pwd}@{ip}:554/cam/realmonitor?channel=1&subtype=0
```
