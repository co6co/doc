# john-1.9.0 生成hash

## ssh2john python 需要进行修改

```
//ssh2john 使用python2 编写

103 #data = base64.decodestring(data)
data = base64.b64decode(data)

154 #saltstr = data[salt_offset:salt_offset+salt_length].encode("hex")
saltstr = data[salt_offset:salt_offset+salt_length].hex()
```

生成hash值

```
python3 /usr/share/john/ssh2john.py id_ed25519 > hash.txt
```

注意：

- john-1.9.0 hash.txt 文件内容 文件名可能有UTF-8
- hachat 文件内容 不能有文件名 [参考](https://hashcat.net/wiki/doku.php?id=example_hashes)

# 使用字典测试密码

```
john --format=ssh --wordlist=您的字典.txt hash.txt
# 可能会出现  Not enough allocatable device memory for this attack
#
hashcat key wordlist.txt
```

# 验证密码：

```
john --show hash.txt # 显示密码
ssh-keygen -y -f <私钥文件>
```
