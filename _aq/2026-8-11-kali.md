# 1. 找到基线

```
# 老牌 Web 服务器
# 查过时组件、危险默认文件、暴露的 .git、默认凭证类问题
# 缺点是噪点多、误报不少，当线索看别当结论
nikto -h http://你的域名

# 安装 nuclei
unzip nuclei_3.0.0_linux_amd64.zip
sudo mv nuclei /usr/local/bin/
# 高精度 CVE/通用漏洞模板扫
#Nuclei 的规则库是社区维护的 YAML 模板，比 Nikto 准很多，扫完直接标 CVE 编号。
nuclei -u http://你的域名
# 首次用先更新模板
nuclei -update-templates # 简写 nuclei -ut
# 如果更新不了 可以使用
# 注意 --recursive
git clone --recursive https://github.com/projectdiscovery/nuclei-templates.git ~/nuclei-templates


#OWASP ZAP —— GUI 全功能（不想敲命令用这个）
#OWASP ZAP 旧称，现在名字 zaproxy   简称 ZAP[产品名称]
# zap-cli 为python 编写的命令行工具
zap-cli -t http://你的域名 -s -a
owasp-zap # zaproxy 开图形界面
安装
apt install zaproxy # zap 本体
pip install zaproxy # API 客户 单独 安装 zap-cli 只会拉到旧版本的OWASP ZAP


# 虚拟化python 安装 zaproxy
# 1. 确保依赖齐全
sudo apt update
sudo apt install -y python3-full python3-venv

# 2. 创建虚拟环境（建议放在项目目录或 ~/.venv）
python3 -m venv ~/zap-venv

# 3. 激活虚拟环境
source ~/zap-venv/bin/activate

# 4. 现在可以正常 pip 安装
pip install --upgrade pip
pip install zaproxy


# 使用
# 启动后台服务
zaproxy -daemon -port 8080 -config api.key=abc123 -config api.disablekey=false

# 查看 ZAP 版本
curl "http://localhost:8080/JSON/core/view/version/?apikey=abc123"
# 让 ZAP 打开某个 URL（触发被动扫描）
curl "http://localhost:8080/JSON/core/action/accessUrl/?apikey=abc123&url=https://目标.com"
# 启动蜘蛛爬取
curl "http://localhost:8080/JSON/spider/action/scan/?apikey=abc123&url=https://目标.com"
# 查看爬取进度
curl "http://localhost:8080/JSON/spider/view/status/?apikey=abc123"
# 启动主动扫描
curl "http://localhost:8080/JSON/ascan/action/scan/?apikey=abc123&url=https://目标.com"
# 获取所有告警
curl "http://localhost:8080/JSON/core/view/alerts/?apikey=abc123"
# 关闭 ZAP
curl "http://localhost:8080/JSON/core/action/shutdown/?apikey=abc123"

# 使用 python
# 用 Python 包写出来是这样（伪代码）

from zaproxy import ZAP
zap = ZAP(apikey='abc123', proxies={'http': 'http://localhost:8080'})
zap.urlopen(target)
scan_id = zap.spider.scan(target)
while int(zap.spider.status(scan_id)) < 100:
time.sleep(2)
zap.ascan.scan(target)
alerts = zap.alerts()


```

# 2. 针对基线继续

```
SQL 注入
sqlmap -u "http://域名/page?id=1" --batch

# WordPress wpscan​
wpscan --url http://域名

#XSS XSStrike​
xsstrike -u "http://域名/search?q=test"

# 弱口令爆破 hydra​
hydra -L user.txt -P pass.txt 域名 http-post-form "/login:user=^USER^&pass=^PASS^:F=失败"
```

使用注意：

1. sqlmap 默认很凶，生产站一定先 `--level=1 --risk=1`，别一上来就` --dbs` 把库扫挂
2. WP 站 wpscan 必跑，插件/主题过期是 WP 站 80% 的入侵入口。
3. SSL/TLS 站：扫 https:// 时 Nikto/Nuclei 都支持，但如果你站证书是自签的
   - Nikto 加 --ignore-ssl-errors（Nuclei）或 -n 相关参数
   - （Nikto 不检查 SSL）
4. Nuclei 可以 `-o result.md`，ZAP 能导出 HTML，改完漏洞后对比复扫

总结步骤：

1. `whatweb + nmap -sV --script=vuln` → 摸家底
2. `ffuf` 扫目录 → 捡隐藏端点
3. `nikto` 快速过一遍 + `nuclei` 精扫 → 自动化漏洞
4. 如果是 WP 站补一个 wpscan，发现注入点再上 `sqlmap`
