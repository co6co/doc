# 字典

`/usr/share/wordlists` 大部分条目其实是符号链接，指向各个工具自己的词表目录

## 目录类

- dirb/​ → /usr/share/dirb/wordlists web目录枚举
- dirbuster/​ → /usr/share/dirbuster/wordlists：DirBuster（Java GUI 工具）专用的目录/文件字典

## 域名类

- amass/​ → /usr/share/amass/wordlists：Amass 子域名枚举用的词表
- dnsmap.txt​ → /usr/share/dnsmap/wordlist_TLAs.txt：DNS 子域名爆破，约 1000 条英文/西班牙文词汇 。

## sql

- sqlmap.txt​ → /usr/share/sqlmap/data/txt/wordlist.txt：sqlmap 用于 SQL 注入时使用的参数字典 。

## WIFI

- fern-wifi/​ → /usr/share/fern-wifi-cracker/extras/wordlists：Fern WiFi Cracker 用的无线密码字典 。
- wifite.txt​ → /usr/share/dict/wordlist-probable.txt：Wifite 进行 WPA 的默认词表 。

## 密码类

- rockyou.txt.gz​ — 当之无愧的"明星字典" 源于 RockYou 社交平台数据泄露事件 sudo gzip -d /usr/share/wordlists/rockyou.txt.gz 如果不想解压，可以用 zcat 管道喂给工具
- fasttrack.txt​ /usr/share/set/src/fasttrack/wordlist.txt 精简 适合第一轮
- john.lst​ → /usr/share/john/password.lst：John the Ripper 配合 John 的规则引擎做变形
- nmap.lst​ → /usr/share/nmap/nselib/data/passwords.lst：Nmap NSE 脚本模块使用的密码表 。
- wfuzz/​ → /usr/share/wfuzz/wordlist：WFuzz 工具的通用 Fuzz 词表，包含参数名、注入 payload 等

- metasploit/​ → /usr/share/metasploit-framework/data/wordlists：Metasploit 框架自用词表
- brutespray/​ → /usr/share/brutespray/wordlist：BruteSpray 默认凭据暴力词表 。
- legion/​ → /usr/share/legion/wordlists：Legion（Sparta 的 fork）工具自带词表 。

## 混合

- /usr/share/seclists # 需要安装 sudo apt install seclists 1.8 GB，Daniel Miessler 维护的 SecLists 项目，几乎涵盖所有场景：子域名、API 密钥、用户名、密码、URL、LFI/RFI、SQLi 字符集等 。实战中很多专业测试人员直接从 seclists 里挑细分子集，而不是无脑上 rockyou
