# 重置密码

## 进入极简救援shell

# 有的系统比如 ubuntu 启动看不到GRUN 需要按 esc 或 Shift 才能看到 GRun

```
# 以 linx 或者 linux16 开头
# 该行从 ro ...... ro 后面的全删修改为 rw init=/bin/bash
# 有的是 ro 改为 rw rd.break

root rw init=/bin/bash
```

## 重新挂在磁盘

```
mount -o remount,rw /
passwd root # 修改密码
sync  #同步避免丢失配置
exec /sbin/init  # 重启系统 #可能不成功 可能缺少必要的启动参数
reboot -f # 重启
echo b > /proc/sysrq-trigger # 重启 (万能重启命令（只要内核没崩就能用）)
```

# 服务

目录:`/etc/systemd/system`

```
[Unit]
Description=My Python Service
After=network.target

[Service]
Type=simple
User=myservice
WorkingDirectory=/opt/myservice
ExecStart=/opt/myservice/venv/bin/python /opt/myservice/app.py
Restart=on-failure
RestartSec=5
Environment="PYTHONUNBUFFERED=1"
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

说明：
Type=simple 适用于前台运行的 Python 程序；Restart=on-failure 让程序崩溃后自动拉起；PYTHONUNBUFFERED=1 保证日志实时刷新到 journald。

```
sudo systemctl daemon-reload
sudo systemctl enable --now nats-server
sudo systemctl status nats-server
sudo journalctl -u nats-server.service -f   # 实时跟踪日志
```
