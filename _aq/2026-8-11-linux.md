## 重新挂在磁盘

```
mount -o remount,rw /
passwd root # 修改密码
sync  #同步避免丢失配置
exec /sbin/init  # 重启系统 #可能不成功 可能缺少必要的启动参数
reboot -f # 重启
echo b > /proc/sysrq-trigger # 重启 (万能重启命令（只要内核没崩就能用）)




# 很多命令都用不了，除了 mount -o remount,rw / 还需要
mount -t proc proc /proc
mount -t sysfs sys /sys

ip link   # 查看网卡 常见名 eth0、ens33、enp0s3
ip link set eth0 up  # 启动网卡
dhclient eth0 # DHCP

ip addr add 192.168.1.100/24 dev eth0
ip route add default via 192.168.1.1

ping -c 2 192.168.1.254

# 开sshd
/usr/sbin/sshd -p 22 \
  -o "UsePAM no" \
  -o "PermitRootLogin prohibit-password" \
  -o "PubkeyAuthentication yes" \
  -o "PasswordAuthentication no"
```

# nc 命令

- v Verbose 详细模式。显示连接状态，非常重要！`nc -v 127.0.0.1 5555`
- n 不解析DNS。加快速度，避免被可疑程序触发反向解析告警。`nc -vn 127.0.0.1 5555`
- z Zero-I/O 扫描模式。不发送数据，只检测端口是否开放（用于批量确认）。`nc -vzn 127.0.0.1 1-5555`
- w Timeout 超时时间。防止连接卡死（后门常会卡住连接）。`nc -vnw 3 127.0.0.1 5555`
- u UDP UDP模式。很多恶意程序用UDP隐藏，`nc -vu 127.0.0.1 5555`
  - Refused（确实关闭了）
  - Open（可能开着，也可能只是对方没理我）

# 服务

目录:`/etc/systemd/system`

```
[Unit]
Description=My Python Service
After=network.target

[Service]
Type=simple
User=myservice
WorkingDirectory=/opt/myservice
ExecStart=/opt/myservice/venv/bin/python /opt/myservice/app.py
Restart=on-failure
RestartSec=5
Environment="PYTHONUNBUFFERED=1"
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

说明：
Type=simple 适用于前台运行的 Python 程序；Restart=on-failure 让程序崩溃后自动拉起；PYTHONUNBUFFERED=1 保证日志实时刷新到 journald。
