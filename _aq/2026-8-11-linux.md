# 重置密码

## 进入极简救援shell

```
# 以 linx 或者 linux16 开头
# 该行从 ro ...... ro 后面的全删修改为 rw init=/bin/bash
# 有的是 ro 改为 rw rd.break

root rw init=/bin/bash
```

## 重新挂在磁盘

```
mount -o remount,rw /
passwd root # 修改密码
sync  #同步避免丢失配置
exec /sbin/init  # 重启系统 #可能不成功 可能缺少必要的启动参数
reboot -f # 重启
echo b > /proc/sysrq-trigger # 重启 (万能重启命令（只要内核没崩就能用）)
```
