﻿#    1.基本

## 1.1. 清屏命令
clear   #本质上只是让终端显示页向后翻了一页,如果向上滚动屏幕还可以看到之前的操作信息。
reset   #完全刷新终端屏幕，之前的终端输入操作信息将都会被清空，这样虽然比较清爽，但整个命令过程速度有点慢，使用较少。
		#值得一提的是reset命令在你的终端控制错乱时非常有用。如输入字符不出现在光标的位置的情况。
		#还有当你敲击回车键时，新提示符并没有出现在新行上
		#而是出现在老提示符的前面。此时reset命令就能用来修正这些问题。

Ctrl+l  #清屏的快捷键，这个是笔者在工作中用得最多的一种清屏方式，清屏效果同clear命令一样。
printf "\033c" #真正的清空了终端屏幕，它的功能跟DOS里CMD.EXE提供的CLS效果很相似。`\033 == \x1B == 27 == ESC`

2.  创建物理卷
	将物理硬盘`分区`初始化为`物理卷`，以便LVM使用
	
	`pvcreate /dev/sda3`    		# 将`/dev/sda3分区`格式化为`物理卷`
	```
	-f：强制创建物理卷，不需要用户确认；
	-u：指定设备的UUID；
	-y：所有的问题都回答“yes”；
	-Z：是否利用前4个扇区。
	```
									# `vgreduce --removemissing centos` 移除未知分区
3. 扩展卷组
	用于动态扩展LVM卷组，它通过`向卷组`中添加`物理卷`来`增加卷组的容量`。
	LVM卷组中的物理卷可以在使用vgcreate命令创建卷组时添加，也可以使用vgextend命令动态的添加。
	
	``` 
	-d：调试模式；
	-t：仅测试。
	```
	
	`vgextend centos /dev/sda3` 	#向卷组`centos`中添加物理卷`/dev/sda3`

```
#创建新PV并将新的PV加入到现有的VG
pvdisplay				  #注意 VG NAME 和VG SIZE 和FREE PE/SIZE
vgextend centos /dev/sdc1 #新的PV 加入VG中； VGSIZE 和FreePE/Size 会发生变化
			              #Couldn't create temporary archive name. / 必须有空间
```

###  2.4.4. 扩展LV(逻辑卷)
```
lvresize -l +1024 /dev/centos/root
# 或者
lvextend -L +10G  /dev/centos/root


lvdisplay				 #再次查看 LVSize 已增大
vgdisplay				 #VG SIZE 已增大 Total PE 已增加 Free PE /Size 已分配完
```

```

## 全局走的代理
export all_proxy="socks5h://127.0.0.1:1080" # socks5h 表示远程解析 dns，如果直接写 socks5 是本地解析 dns

#查看
export
curl cip.cc
```

###  方法1
```
function proxy_on(){
    export all_proxy=socks5://127.0.0.1:1080
    echo '********  开启当前终端代理  ********'
    cur cip.uu
}
function proxy_off(){
    unset all_proxy
    echo '******** 关闭当前终端代理 ********'
}
```
```
source /etc/profile  # 使之生效 仅当前窗口生效
proxy_on


# 全局生效
sudo vi ~/.bashrc
增加该行：source /etc/profile
```
