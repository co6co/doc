# 颜色
`蓝色`的代表那是USB 3.0，`黑色`的代表USB 2.0，
如果电脑上只有黑色的，那基本上可以说这台电脑只有USB 2.0，没有USB 3.0，
- USB 3.0支持，
- 没有前置USB 3.0接口， 看看主板上的接口是否有非黑色的USB接口，如果有，那大概率是USB 3.0了。


红色/黄色 		电流可能会达到`1A`以上（标准的为`0.5A`）

# 标志
- `SS+`		SuperSpeed USB接口（USB 3.0）
- `S+`		USB 2.0

# 速度
`USB 2.0`的理论速度只有`480Mbps`， `USB 3.0`的速度达到了`5Gbps`，`USB 3.1`高达`10Gbps`
