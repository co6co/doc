#### **处理器性能**
- **MT7620**: 单核处理器，主频仅为 580 MHz，性能较低，适合入门级设备。
- **MT7621**: 双核处理器，主频提升至 880 MHz，性能显著优于 MT7620，适合中端设备。
- **MT7621A**: 与 MT7621 相同的双核架构和主频，但经过优化，整体性能更稳定。

#### **网络能力**
- **MT7620**: 仅支持百兆以太网，适用于低带宽需求的场景。
- **MT7621 和 MT7621A**: 支持千兆以太网，适合高带宽需求的场景。

#### **Wi-Fi 能力**
- 三者均内置 2.4GHz 802.11n Wi-Fi（3T3R），但 **MT7621A 的抗干扰能力更强**。

#### **硬件加密加速**
- **MT7620**: 基本支持，但性能较弱。
- **MT7621**: 支持硬件加密加速，但能力有限。
- **MT7621A**: 支持更强大的硬件加密加速，适合需要高性能加密的应用。

#### **扩展性**
- **MT7620**: 无 PCIe 或 SDXC 支持，扩展性较差。
- **MT7621**: 无 PCIe 或 SDXC 支持。
- **MT7621A**: 支持 PCIe 和 SDXC，扩展性强。

### **功耗对比**
- **MT7620**: 由于性能较低，功耗相对较小，但效率不高。
- **MT7621**: 性能更高，但功耗也相应增加。
- **MT7621A**: 经过功耗优化，能够在相同性能下实现更低的功耗。

### **应用场景对比**

| 芯片型号             | 典型应用场景                                      |
|----------------------|--------------------------------------------------|
| **MT7620**           | 入门级路由器、无线 AP、智能家居设备               |
| **MT7621**           | 中端路由器、小型 NAS、企业级无线 AP              |
| **MT7621A**          | 高端路由器、NAS、边缘计算设备、高性能网络设备    |

### 总体来说：
- **MT7620**: 适合预算有限、对性能要求不高的入门级设备，成本最低，但功能和扩展性有限。
- **MT7621**: 适合中端市场，提供更高的性能和千兆网络支持，性价比高。
- **MT7621A**: 适合高端市场，具备更强的性能、更好的扩展性和更低的功耗，是高性能设备的理想选择

# 4 常见分区
## 4.1 bootloader 
- **名称**：`boot`, `u-boot`, `uboot-env`, `bootloader`
- **作用**：
  - 存储设备启动时运行的第一个程序（Bootloader），负责初始化硬件并加载操作系统内核。
  - 通常由设备厂商提供，设计为相对稳定的部分。
- **注意**：
  - 修改或覆盖此分区可能导致设备无法启动（变砖）。
  - 通常不建议用户直接操作此分区。
  
## 4.2. 内核分区
- **名称**：`kernel`, `linux`
- **作用**：
  - 存储 Linux 内核镜像，由 Bootloader 加载并运行。
  - 包含设备驱动程序和其他核心组件。
- **特点**：
  - 在系统升级时会被更新。
  - 通常与文件系统分区分离，便于单独更新。

## 4.3. 文件系统分区
- **名称**：`rootfs`, `rootfs_data`, `firmware`
- **作用**：
  - 存储操作系统的文件系统，包括配置文件、应用程序和其他用户数据。
  - `rootfs` 是初始的只读文件系统，而 `rootfs_data` 通常是可写的扩展分区，用于存储用户配置和动态数据。
- **特点**：
  - 在系统升级时会被更新。
  - 用户可以修改此分区中的内容。

## 4.4 配置分区
- **名称**：`config`, `factory`, `nvram`, `art`
- **作用**：
  - 存储设备的出厂配置或用户配置信息。
  - 包括无线网络设置、MAC 地址、序列号等。
- **特点**：
  - 通常不会被系统升级覆盖。
  - 某些设备会将配置数据存储在独立的分区中，以便在固件重置时保留重要信息。

## 4.5. 日志分区
- **名称**：`log`, `crashdump`
- **作用**：
  - 存储设备运行日志或崩溃时的调试信息。
  - 用于诊断和调试问题。
- **特点**：
  - 通常是一个较小的分区，写入频率较高。

## 4.6. 空闲分区
- **名称**：`reserved`, `unused`
- **作用**：
  - 未分配或预留的分区，供未来使用。
- **特点**：
  - 通常为空，不包含任何数据。
