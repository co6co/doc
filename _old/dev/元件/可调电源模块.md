# 2. 功率半导体元器件
晶体管领域）的代表产品还有MOSFET、BIPOLAR等，它们主要被用作半导体开关。
关速度，BIPOLAR适用于中速开关，MOSFET则适用于高频领域
IGBT是输入部为MOSFET结构、输出部为BIPOLAR结构的元器件，通过这两者的复合化，既是使用电子与空穴两种载体的双极元件，同时也是兼顾低饱和电压（与功率MOSFET的低导通电阻相当）和较快的开关特性的晶体管。
尽管其具有较快的开关特性，但仍比不上功率MOSFET，这是IGBT的弱点。

# 2.1 IGBT 管 （Insulated Gate Bipolar Transistor 绝缘栅双极晶体管）
场效应管与三极管的结合体

- 输入端（栅极）  -->电为器中间脚
- 接地端（发射极）
- 集电极

可以改变栅及电压大小，以实现可调电压目的

## 2.2 MOSFET
指半导体元件的结构为Metal（金属）- Oxide（半导体氧化物）- Semiconductor（半导体）的三层结构的Field-Effect Transistor（场效应晶体管）。

## 2.3 BIPOLAR
是指使用了双极性元件，将称为p型和n型的两种半导体构成n-p-n及p-n-p结构的电流工作型晶体管。
