# 1 基础知识
使用`NADA`闪存存储数据;Trim指令也被称为disable delete notify（禁用删除通知）
1. 查看TRIM 是否 已禁用
```
>fustil behavior query disabledeletenotify
Disabledeletenotify = 0
#如果返回数据为 1，则表明Trim已禁用。如果返回数据为0，则表明Trim已禁用激活
>fustil behavior query disabledeletenotify 0|1   #设置 
```
2. 用文件恢复软件恢复误删的文件
