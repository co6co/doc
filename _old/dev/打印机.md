# 2. 打印协议
- ipp 631
	更多用于获取打印属性的GET_PRINTER_ATTRIBUTES
- printer-job-language 又称RAW协议  9100
	此端口发送的数据打印机直接打印，除非发送正确的printer-job-language协议内容
- ldp 151
	Line Printer Daemon protocol,与踹死TCP/IP协议共享服务器的打印资源；
	服务器以Daemon 方法允许一个进程，客户机通过lp，lpr，lpd，lprm等命令实现增加打印机就就，查询和删除打印队列等操作。
