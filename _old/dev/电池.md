# 正常的情况
	Vdd为高电平，Vss，VM为低电平，DO、CO为高电平，当Vdd，Vss，VM任何一项参数变换时，DO或CO端的电平将发生变化; 
	两个MOSFET都处于导通状态，电池可以自由地进行充电和放电，由于MOSFET的导通阻抗很小，通常小于30毫欧，因此其导通电阻对电路的性能影响很小。此状态下保护电路的消耗电流为μA级，通常小于7μA。
# 恒流充电 4.2 /4.1 V
	充电器电路失去控制，4.2V后继续恒流充电,被充至超过`4.3V`时,
	带有保护电路,IC检测到电池电压达到`4.28V`(IC决定)，`“CO”`脚将由高电压转变为零电压，使`V2`由导通转为关断（延时时间的长短由C3决定，通常常为`1s`），从而切断了充电回路
	此时由于`V2`自带的`体二极管VD2`的存在，电池可以通过该二极管对外部负载进行放电

# 过放电保护
	电压降至`2.5V`时，其容量已被完全放光，继续放电，将造成电池的永久性损坏
	IC检测到电池电压低于`2.3V`，`“DO”`脚将由高电压转变为零电压，使`V1`由导通转为关断（延时时间的长短由C3决定，100ms），切断了放电回路，
	此时由于`V1`自带的`体二极管VD1`的存在，充电器可以通过该二极管对电池进行充电	，
	IC会进入`低功耗状态`，整个保护电路耗电会小于`0.1μA`
# 短路保护
	回路电流大到使`U>0.9V`(值由控制IC决定,小于7微秒),其`“DO”`脚将迅速由高电压转变为零电压，使`V1`由导通转为关断,
	电路中还有一个重要元件，就是`MOSFET`，它在电路中起着开关的作用，由于它直接串接在电池与外部负载之间； MOSFET较好时内阻就小
# 过电流保护
	其放电电流最大不能超过`2C`，当电池`超过2C`电流放电时，将会导致电池的`永久性损坏`或`出现安全`问题
	放电电流在经过串联的`2个MOSFET`时，其两端电压 `U=I*RDS*2`，RDS为单个MOSFET导通阻抗，IC上的`“V-”`脚对该电压值进行检测，
	当回路电流大到使`U>0.1V`，其`“DO”`脚将由高电压转变为零电压，使V1由导通转为关断 （延时时间的长短由C3决定，13ms)
