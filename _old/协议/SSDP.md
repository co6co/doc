# simple Server Discovery Protocol 简单网络发现协议
网络客户提供一种无需任何配置、管理和维护网络设备服务的机制；
采用基于通知和发现路由的多播发现方式实现；
协议客户端在保留的多播地址：`239.255.255.250:1900` 或`FF0x::C ` 发现服务，
每个设备服务也在此地址上监听服务发现请求；
发现请求与此服务匹配，此服务会使用单播方式响应。

常见的请求消息：
- 服务通知
	设备和服务使用此类通知消息声明自己的存在
- 查询请求
    协议客户端用此请求查询某种类型的设备和服务。

请求消息中包含设备的特定信息或某项服务的信息；
设备类型、标识符和指向设备描述文档的URL地址；
