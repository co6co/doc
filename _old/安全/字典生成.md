# 字典生成

## 1.1 crunch

- @:将插入小写字符
- ，:将插入大写字符
- % :将插入数字
- ^ :将插入符号

```
# 固定6位 bbs+三位数字
crunch 6 6 -t bbs%%% -o num.txt

# (a，b 或 c)+ 数字(1，2 或 3) + 符号(ANY)
crunch 3 3 abc + 123 -t @%^ -o kali.txt

#两个数字（1、2 或 3）+ 小写字母 + 符号 （ANY）
crunch 4 4 + + 123 + -t %%@^ -o kali.txt //+起到了两个占位符
```

`crunch 4 7 Pass123 -z gzip -o START` 压缩
