函数式编程
在就Java并不天然支持函数是头等公民；
尝试模拟出一种函数类型：
```
interface Function<Arg,Return>{
	Return apply(Arg arg);
}

Function<String,Interger> stringLength=new Function<String,Integer>(){
	public Interger apply(String arg){
		return arg.length();
	}
};

int result= stringLength.apply("hello");


```

希望实现一个print 方法，Return 的类型用什么表示；
void，java不能这样使用，只能为 Void, `interface Function<Arg,Void>`由于Void没有实例 返回一个null
这种做法严格意义上讲，相当丑陋；
Java 8实际解决的方法式通过引用 Action<T> 这种函数式接口来解决问题；

虽然解决了问题，但是这种方案不可避免的创造了大理的重复的类，最好的解决办法是：
引入一个单例类型Unit，除了不代表任何意义意外，它与其他常规类型并没有什么差别；
