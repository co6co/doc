# 1. 知识点
## 1.1 RequestMapping
`produces`  指定返回值类型及返回值的字符编码 
	返回json  功能与 `@ResponseBody`  类似
`consumes` 提交内容格式：`Content-Type` 的 `application/json, text/html;`
	请求内容格式 与 `@RequestBody ` 功能类似
