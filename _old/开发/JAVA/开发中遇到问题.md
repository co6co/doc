# 问题1
nginx 设置Host 后 代理 JAVA WEB 后返回 Bad Request
粗略查询 类 `Http11Processor`  `hostValueMB = headers.getUniqueValue("host");` headers 中的host 的不能重复 
`MimeHeaders headers;`
过nginx 会增加个 `host[4]=fetch.localhost` ?待查的问题 
经查询时是在 nginx 中重复设置：`proxy_set_header Host fetch.$host;`

# @Override 
`@Override is not allowed when implementing interface method`

因为：module的language level是6以下，我们需要修改module的language的level为6或6以上。
Project Settings > Modules > 选择所在的module > 修改Language level为6或6以上，有时候还需要重启项目。
