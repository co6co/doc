# loader
webpack 只能理解 JavaScript 和 JSON 文件，这是 webpack 开箱可用的自带能力;
loader 让 webpack 能够去处理其他类型的文件，并将它们转换为有效 模块

在 webpack 的配置中，loader 有两个属性：
- test 属性，识别出哪些文件会被转换。
- use 属性，定义出在进行转换时，应该使用哪个 loader。

## webpack.config.js 中的配置

嘿，webpack 编译器，当你碰到「require()/import 语句中被解析为 '.txt' 的路径」时，在你对它打包之前，先 use(使用) raw-loader 转换一下。
```
const path = require('path');

module.exports = {
  output: {
    filename: 'my-first-webpack.bundle.js',
  },
  module: {
    //使用正则表达式匹配文件时， 不要为它添加引号
    rules: [{ test: /\.txt$/, use: 'raw-loader' }], 
  },
};


//vue.config.js
config.module
    .rule('ts')
    .test(/\.ts$/)
    .use('ts-loader')
    .loader('ts-loader')
    .end()  
```


# tsconfig.json
目录下存在一个tsconfig.json文件，那么它意味着这个目录是TypeScript项目的根目录。
文件中指定了用来编译这个项目的根文件和编译选项
```
"compilerOptions": {
        "module": "system",
        "noImplicitAny": true,
        "removeComments": true,
        "preserveConstEnums": true,
        "outFile": "../../built/local/tsc.js",
        "sourceMap": true
},
	
///指定需要编译的文件
files: ["core.ts",]
//使用"include"和"exclude"属性
"include": [
        "src/**/*"
    ],
"exclude": [
	"node_modules",
	"**/*.spec.ts"
]
```
