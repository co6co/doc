# 常用方法
```
//style 选项中开启 enablePullDownRefresh
onPullDownRefresh(parm{success,fail,complete}) {// complete 失败成功都会执行
        console.log('refresh');
        setTimeout(function () {
            uni.stopPullDownRefresh();  //当处理完数据刷新后，uni.stopPullDownRefresh 可以停止当前页面的下拉刷新。
        }, 1000);
}
```
