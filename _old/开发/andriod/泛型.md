# 泛型
java 中的代码
```
Apple[] appleArray=new Apple[10];
Fruit fruitArray= appleArray;      //允许
fruitArray[0] =new Banana(0.5);		//编译通过，运行报 ArrayStoreException

List<Apple> appleList=new ArrayList<Apple>();
List<Fruit> fruitList=appleList;		//不允许
```

数组是协变的，list是不变的，即Object[] 是所有对象数组的父类，
而List<Object>却不是List<T> 的父类；

Java 中泛型是类型擦除的（伪泛型），即无法在运行时获得一个对象具体的类型；

数组运行时可以获取自身的类型，而List<Apple>在运行时只知道自己是一个List，无法获取泛型参数的类型；
Java数组是协变的。若A是B的父类，则A[] 也是B[]的父类；
假如给数组加入泛型后，将无法满足数组协变的原则（运行时无法知道数组的类型）；

Kotlin中的泛型机制和java中是一样的，上面的特性在Kotlin中一样适用；
不同的是Kotlin 中的数组是支持泛型的（不在协变，特性和List一样）；
```
val appleArray=arrayOfNulls<Apple>(3)
val anyArray:Array<Any?>=appleArray  //不允许
```

# 向后兼容
老版本的java文件编译后，可以在新版本的JVM上运行；

在1.5前是没有泛型的：
在没有泛型的语言上支持泛型，一般有两种方式（以集合为例）：
- 全新设计一个集合框架，不保证兼容老的代码；需要适用新的语法；
- 在老的集合框架上改造，增加一些特性，兼容老代码的前提支持泛型；

泛型特性：类型检查、类型自动转换；
类型检查编译器在编译前就会帮我们进行类型检查，所有类型擦除不影响类型检查；
类型自动转换：
```
ArrayList<String> stringList=new ArrayList<String>();
String s=stringlist.get(0);
```
get方法返回的值的类型就是List泛型的参数类型，通过ArrayList 源码可知，通过强制类型转换来实现的；
也可从字节码得到验证。
```
   public E get(int index) {
        if (index >= size)
            throw new IndexOutOfBoundsException(outOfBoundsMsg(index)); 
        return (E) elementData[index];
    }
	
	@SuppressWarnings("unchecked")
    E elementData(int index) {
        return (E) elementData[index];
    }
	
```

# 泛型擦除
通常情况，我们并不在意他的类型是否被擦除，但有些场景却需要知道运行时的泛型参数，
如果序列化和反序列化时:
```
open class Plate<T>(val t:T,val clazz:Class<T>){
}
//有的时候我们无法获取泛型的类型：
ArrayList<String>::class.java //不被允许
```

## 匿名内部类获取泛型
```
val list1=ArrayList<String>()
val list2=object: ArrayList<String>(){}  //匿名内部类：

println(list1.javaClass.genericSuperclass)  // java.util.AbstractList<E>
println(list2.javaClass.genericSuperclass)  // java.util.ArrayList<java.lang.String >

```

```

open class GenericsToken<T> {
    var type: Type =Any::class.java
    init {
      var superClass=  this.javaClass.genericSuperclass
        type= (superClass as ParameterizedType).actualTypeArguments[0]
    }
}
//test
val gt=object:GenericsToken<Map<String,String>>(){}
println(gt.type)
```

## 内联函数获取泛型
```
inline fun <reified T> getType(){
	return T::class.java
}
```

# 协变和逆变
in 和out是一个对了吗，in代表泛型参数类型逆变，out代码泛型参数类型协变，
同时他们又与泛型不变对立，统称**型变**，
他们可以用不同的方式使用：

- 声明处型变
	```
	public interface List<out E>:Collection<T>{}
	```
- 使用处型变

	从Double数组中拷贝到另一个Double数组中：
	```
	fun <T> copy (dest:Array<T>,src:Array<T>){
		if(dest.size<src.size) throw IndexOutOfBoundsException()
		else src.forEachIndexed{index,value->dest[index]=src[index]}
	}
	```
	上面的COPY可以将同一种类型的拷贝，但不支持如 Array<Double> 拷贝到 Array<Number>中;

	利用所学的泛型变形实现如下:
	```
	//in 版本
	fun <T>copyIn(dest:Array<in T>,src:Array<T>){
		
	}
	//out 版本
	fun <T>copyIn(dest:Array<T>,src:Array<out T>){
		
	}

	//测试
	var dest=arrayOfNulls<Number>(3)
	val src=arrayOf<Double>(1.0,2.0,3.0)

	copyIn(dest,src) //允许  T is Double，dest 能接收Array<Double> 类型的子类比如: Array<Number> (根据逆变特性 自己理解)
	copyOut(dest,src) //允许 T is Number，dest 能接收 Array<Number>的子类比如  Array<Double>
	```
	in 版本 dest 可以接收T类型的父类型ARRAY，out版本，dest可以接收T类型的子类型；
	接收 指定是参数的接收，不管函数体

Kotlin与Java的型变比较

||协变|逆变|不变|
|-|-|-|-|
|Kotlin|实现方式：`<out T>`,只能作为消费者，只能读取不能增加|实现方式：`<in T>`,只能作为生成者，只能增加，读取受限 |实现方式：`<T>`,可增加，可读取|
|JAVA|实现方式:`<? extend T>`,只能作为消费者，只能读取不能增加|实现方式：`<? super T>`，只能作为生成者，只能增加，读取受限|实现方式:`<T>`,可增加，可读取|

## 类型通配符：
java中：`?` ,Kotlin: `*`
```
val list:MutableList<*>=mutableListOf(1,"Kotlin")
list.add(2.0) //出错；
```
MutableList<*>与MutableList<Any?> 不是同一种列表，后者可以增加任意元素，
前者只是通配某一种类型，但是编译器不知道是那种类型；

前面所有的协变不能增加元素，类型通配符，仅是一种语法糖，也是通过协变的来实现的，
`MutableList<*>`本质上是:`MutableList<out Any?>`.
