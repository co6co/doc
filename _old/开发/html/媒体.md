# blob对象
html5中 中的blob对象在赋给Video标签后生成一串标记，blob对象包含的数据浏览器内部会解析
``` html5
<body>
	<video controls id="sound"> </vodeo>
	<script>
		var xhr = new XMLHttpRequest();
		xhr.open('POST','./test.do',true);
		//设置请求结果类型为blob
		xhr.responseType = "blob";
		//请求成功回调
		xhr.onload = function(e){
			if( this.status = 200 ){
				var blob= this.response;
				document.getElementById("sound").src=blob;
			}
		};
		xhr.send();
	</script>
</body>
```
