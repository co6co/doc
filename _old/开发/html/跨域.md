# 1. option
option 请求；
主要用途：
- 1. 获取服务器支持的HTTP请求方法；
- 2. 检测服务器的性能
	 AJAX 进行跨域请求时的预检，以判断实际发送的请求是否安全

服务器认为options 请求时无危险性且认可，

# 2. CORS（跨域资源共享）
CORS是一种网络浏览器的技术规范，它为Web服务器定义了一种方式，
允许网页从不同的域访问其资源。而这种访问是被同源策略所禁止的。
CORS系统定义了一种浏览器和服务器交互的方式来确定是否允许跨域请求。
- 前端
  使用XmlHttpRequest发起Ajax请求，绝大部分浏览器都支持CORS
- 服务器端
  默认的到 CORS Access Deny;
