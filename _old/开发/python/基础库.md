setuptools 是 distutils 增强版，不包括在标准库中。其扩展了很多功能，能够帮助开发者更好的创建和分发 Python 包
# 3. distutils

distutils 是标准库中负责建立 Python 第三方库的安装器，使用它能够进行 Python 模块的安装和发布。distutils 对于简单的分发很有用，但功能缺少。

## 1.1.1  加密 crpto 库
crypto是GPG加解密库，该库已于2016年停更，且python-gnupg库才是最主流的GPG加解密库。

crypto在python上面的名字是pycrypto它是一个第三方库，但是已经停止更新三年
pycryptodome就来了，它是pycrypto的延伸版本，用法和pycrypto 是一模一样的；
```
pip install pycryptodome
```

# 多线程 https://www.cnblogs.com/yoyo1216/p/15726319.html
`concurrent.futures`是3.2 引入的新模块，为异步执行可调用对象提供高层接口；
可以使用ThreadPoolExecutor和ProcessPoolExecutor 进行编程，两者实现了同样的接口，接口由Executor定义；
该模块提供两大类，一是执行类Executor，二是Future类，执行其用来管理工作池，future用来管理工作计算出来的结果；通常不直接操作future对象（通过丰富的API）

## concurrent.futures.Executor 类
定义的方法有：`submit(fn, *args, **kwargs)`;
`map(func, *iterables, timeout=None, chunksize=1)`
