# 1 钩子
## 1.1 重新初始化钩子
```
void IoRegisterDriverReinitialization(
	[in]	PDRIVE_OBJECT DriverObject,
	[in]	PDRIVER_REINITIALIZE DriverReinitializtionRoutine,
	[in,optional] PVOID	Content
)
```

函数的作用可以在DriverEntry 执行完毕之后，重新执行一次初始化.全驱动有且只能注册一个. 
且 在DriverEntry 返回 STATUS_SUCCESS 之后才会被执行.

## 1.2 进程钩子
可以拦截进程,监控进程等等
```
# Windows 2000 
NTSTATUS PsSetCreateProcessNotifyRoutine(
  [in] PCREATE_PROCESS_NOTIFY_ROUTINE NotifyRoutine,
  [in] BOOLEAN                        Remove
);

# Windows Vista with SP1 and Windows Server 2008.
NTSTATUS PsSetCreateProcessNotifyRoutineEx(
  [in] PCREATE_PROCESS_NOTIFY_ROUTINE_EX NotifyRoutine,
  [in] BOOLEAN                           Remove
);

# Windows 10, version 1703
NTSTATUS PsSetCreateProcessNotifyRoutineEx2(
  [in] PSCREATEPROCESSNOTIFYTYPE NotifyType,
  [in] PVOID                     NotifyInformation,
  [in] BOOLEAN                   Remove
);
```

上述API 其实本质都是将我们设置的函数设置到一个 数组中 
而操作系统是通过 数组中 中记录的类型来识别 
当前数组中的函数地址是哪个函数创建的. 
类型分别是 `2 4 6` 
如果是2 那么代表就是 PsSetCreateProcessNotifyRoutine 创建的, 
那么操作系统调用我们的回调的时候就会按照回调函数的参数来进行传参.
2 4 6 是通过逆向得出的(不保证后是否会改变).

1.7 关机回调
可以监控关键回调.在关机的时候做一些处理.
```
注册:

NTSTATUS IoRegisterShutdownNotification(
  [in] PDEVICE_OBJECT DeviceObject
);
取消注册:

void IoUnregisterShutdownNotification(
  [in] PDEVICE_OBJECT DeviceObject
);
```
另一个注册回调(下面说区别)
```
NTSTATUS IoRegisterLastChanceShutdownNotification(
  [in] PDEVICE_OBJECT DeviceObject
);
```
用法:

注册好关机回调之后, 我们需要 在派遣函数中指定 IRP_MJ_SHUTDOWN  的回调函数,操作系统检测到关机的时候则会调用这个派遣函数

IoRegisterLastChanceShutdownNotification 和 IoRegisterShutdownNotification 的区别是 时机问题,前者会在文件系统刷新关闭之后调用,

后者则不是. 后者接受的通知比前者强. 关于文件系统刷新无法正确解释.举个例子自己体会. 后者关机回调里面可以设置注册表(注册表也可以说是文件,没刷新) 可以读写注册表的值. 而前者因为 文件系统刷新(可能处理了文件) 在回调里面操作注册表则不可以操作了. 包括打开 Key setvalue都会失败.

1.9 为驱动对象申请一块上下文缓冲区.
主要使用函数:
```
NTSTATUS IoAllocateDriverObjectExtension(
  [in]  PDRIVER_OBJECT DriverObject,                  //驱动的驱动对象
  [in]  PVOID          ClientIdentificationAddress,   //指定要分配的唯一标识符
  [in]  ULONG          DriverObjectExtensionSize,     //要分配的大小
  [out] PVOID          *DriverObjectExtension         //完成时指向分配的上下文区域的指针。 
);
```
与之配套使用的函数如下,来获取对应的context使用
```
__drv_aliasesMem PVOID IoGetDriverObjectExtension(
  [in] PDRIVER_OBJECT DriverObject,                  //驱动对象
  [in] PVOID          ClientIdentificationAddress    //标识符,要获取哪个标识符(字段)上申请的上下文信息.
);
```
示例代码:(逆向的来)
```
 status = IoAllocateDriverObjectExtension(DriverObject, &DriverObject->DriverExtension, 0x2000u, &CallbackContext);
 if ( IoGetDriverObjectExtension(DriverObject, &DriverObject->DriverExtension) != CallbackContext )
      ExFreePoolWithTag(CallbackContext, 0);
	  
```
