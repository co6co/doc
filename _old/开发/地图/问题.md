# 1. 问题描述
在工作中开发一个地图，本地可以正常运行的，发布到客户现场，提示“webgl context must not be null, please enable webgl in your browser settings!” 错误，导致后面的逻辑全部无法正常运行

解决办法
在浏览器地址栏输入 chrome://flags/ 。
将 Override software rendering list 选项设为"Enabled"。、
WebGL Draft Extentions 选项改为enbale。
Chrome 73之后的版本, 确保Choose ANGLE graphics backend 为"OpenGL"。
