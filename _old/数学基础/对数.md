# 定义
如果a^x=N(a>0,且a≠1)，则x叫做以a为底N的对数,记做x=log(a)(N)，其中a叫做对数的底，N叫做真数
将以10为底的对数叫做·`常用对数(lg)`，以e为底的对数称为`自然对数(ln)`
# 总结
负数与零无对数

```
logₐ (1)		=0
logₐ (a)		=1
logₐᵇ * logbᵃ	=1
logₐ（MN）		=logₐM+logₐN
logₐ（M/N）		=logₐM-logₐN
logₐ（1/N）		=-logₐN
logₐ（ₐᵏ）		=k
logₐMⁿ			=nlogₐM
-logₐ(t/n)		=logₐ(n/t)
```
