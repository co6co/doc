# 1. 引导
## 1.1 准备
- 引导工具 [ARPL](https://github.com/fbelavenuto/arpl/releases/tag/v1.1-beta2a)
	
	文件都是压缩包需要解压才能使用：
	arpl-1.1-beta2a.img.zip
	arpl-1.1-beta2a.vmdk-dyn.zip 
	arpl-1.1-beta2a.vmdk-flat.zip 
- U盘：8GB
- 写盘工具：[RUFUS](https://rufus.ie/downloads/) 【黑群晖引导文件提前写入U盘内引导物理机】


- 群晖系统
	- 根据引导工具设置 Choose a build Number **编译版本号**下载对应系统
	- 群晖官网【SYNOLOGY】下载系统
	- 群晖系统最小10G
	- NAS + DS918+
		比如：7.1.1-42962-1 【42962 就是buildNumber，-1：版本号后面还有数字为升级包】
		升级包只有几十兆 ，安装包有300M左右

## 1.2 引导
- vm 使用虚拟机现有虚拟磁盘引导[arpl.vmdk,使用不带 fat的vmdk 文件]引导
- 物理机 使用 RUFUS写入U盘引导
