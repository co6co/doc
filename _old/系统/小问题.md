1. 关机后鼠标还亮
BIOS：->将USB Resume from Suspend或USB Wake Support （支持USB唤醒功能）关闭掉

2. 取消windiws 10 ctl +shift +b
```
[HKEY_CURRENT_USER\Software\Microsoft\InputMethod\Settings\CHS]
"EnableOpenEmoticonSymbolView"=dword:00000000
```

2. 虚拟机安装不上VMware Tools 工具
VMware Tools安装：安装程序无法自动安装 Virtual Machine Communication Interface Sockets (VSock)驱动程序
由于微软从2019年12月3日已将Windows驱动程序签名更改为使用SHA-2算法，下载支持SHA-2代码签名的补丁kb4474419安装后即可。
https://www.catalog.update.microsoft.com/search.aspx?q=kb4474419

3. 网络硬盘映射为
```
-- 1. 启动xp_cmdshell
sp_configure 'show advanced options',1
reconfigure
go
sp_configure 'xp_cmdshell',1
reconfigure
go
-- 2. 映射
exec master..xp_cmdshell 'net use M: "\\vmware-host\Shared Folders'
-- 检查是否成功
exec    master..xp_cmdshell 'dir M:'  
```
附加数据库
```
USE MASTER;

EXEC sp_detach_db @dbname = 'dbName'; 
EXEC sp_attach_single_file_db @dbname = 'dbName', 
     @physname =   'D:\Program Files\DATA\dbName.mdf'   

```
 
 
4. BitLock
BitLocker正在等待激活，怎样可以关闭
`manage-bde -off X:`

5. 服务超时设置：
```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\ServicesPipeTimeout DWORD  毫秒
```

5. 打印机出现 未连接
方法1：
卸载**共享主机**补丁 `KB5005569/KB5005573/KB5005568/KB5005566/KB5005565` 

方法2：
``` 
Windows Registry Editor Version 5.00
[HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Print]
"RpcAuthnLevelPrivacyEnabled"=dword:00000000

[HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows NT\Printers\PointAndPrint]
"RestrictDriverInstallationToAdministrators"=dword:00000000 
```
