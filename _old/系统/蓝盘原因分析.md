# 1. 概述
`DPC_WATCHDOG_VIOLATION ` 蓝屏代码大多是由于硬件驱动问题造成的，可通过回退、更新或卸载驱动来修复蓝屏；
日志目录`C:\Windows\Minidump`,扩展名`*.dmp。`

# 2. 分析步骤
## 2.1 蓝屏日志
- WinDbg Preview 微软官方推出的系统调试工具

启动WinDbg Preview 会自动检测到最新的蓝屏日志，
蓝屏原因多在日志末尾几行，通过分析末尾日志，可以找出蓝屏的进程[不能强行删除未知文件]
