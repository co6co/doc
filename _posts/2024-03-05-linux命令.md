# 服务管理
```
systemctl enable xxx.service # 开机启动
systemctl is-enabled xxx.service # 服务是否开机启动
systemctl list-unit-files --type=service --state=enabled	#查看所有启动的服务
systemctl list-units --type=service --all	#查看所有服务
```
## 创建python服务
1. 创建服务：
```
#/usr/lib/systemd/system/data-audit.service
[Unit]

Description=audit service
After =network.target,syslog.target

[Service]

ExecStart=/home/xx/work/start.sh
User=root
Group=root

[Install]

WantedBy=multi-user.target 
```
2. start.sh 文件
```
#!/bin/bash

cd /home/xx/work/audit-server
nohup /home/cy/.conda/envs/web/bin/python app.py >> /home/xx/logs/app.log

```
