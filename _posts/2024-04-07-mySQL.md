# 1. 修改mysql超时配置
应用长时间(默认8小时)没有执行sql 会超时，出现
**error:(pymysql.err.OperationalError) (2013, 'Lost connection to MySQL server during query')** 错误
```
set global wait_timeout=60;
set GLOBAL interactive_timeout=60;
show variables like '%timeout';
```

# 2. sqlalchemy 设置回收时间
`
sqlalchemy.exc.OperationalError: (pymysql.err.OperationalError) (2013, 'Lost connection to MySQL server during query')
`
```
# 方法1 设置回收时间
engine = create_engine(url, pool_recycle=600) # 回收时间设置为 10 分钟
# 方法2 执行操作前检查
engine = create_engine("mysql+pymysql://root:passwd@host/db", pool_pre_ping=True,pool_recycle=1800) # 执行前检查 
# 方法3 不使用连接池
engine = create_engine("mysql+pymysql://root:passwd@host/db", pool_pre_ping=True,pool_recycle=-1) #不使用连接池

```

# 3.  MySQL 联表查询去重 & 解决 DISTINCT  异常：Expression #1 of ORDER BY clause is not in SELECT list
5.7.5以上版本，我在查询的时候使用了distinct关键字，搭配了order by去使用，但是我排序的字段不是我distinct的字段
```
SELECT @@GLOBAL.sql_mode;
-- ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION

SELECT @@SESSION.sql_mode;
-- ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION

-- 去掉“ONLY_FULL_GROUP_BY,”后的值
set @@GLOBAL.sql_mode='STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION'
set @@SESSION.sql_mode='STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION'
```
