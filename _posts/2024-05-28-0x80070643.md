#  解决的可能方法
## 1. 方法1 
```
权限有问题。如果安装了某些优化软件，
可能会将“完全读取”权限给，只给“读取”权限。只要手动打开“完全读取”权限
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_RESTRICT_ABOUT_PROTOCOL_IE7
```

## 2. 方法2
经过一方查找在日志中找到原因：
```
Error 2203:  Database: C:\windows\Installer\inprogressinstallinfo.ipi. Cannot open database file. System error -2147287037

```
后经过 msiexec 的进程/创建文件分析 发现 `C:\windows\system32\%windir%\TEMP\~DF7D9A7EE43ECD9DAE.TMP`,
猜测可能是因为`C:\windows\system32\%windir%\TEMP\` 这个路径导致的，于是导建立了相应路径,再次安装发现尽然可以，这个问题陆陆续续用了三天才知道原因。
至于为什么 msiexe的临时路径会变成 `C:\windows\system32\%windir%\TEMP\` ,还未知，查看了相关的环境变量 用户和系统的都是正常的。
