# 1.  bs4对象 
```
from bs4 import BeautifulSoup
# 格式化输出
print(soup.prettify()) 
```
复杂的树形结构，每个节点都是 Python 对象，所有对象可以归纳为 4 种:
```
- Tag                   HTML 中的一个个标签 eg. a title head p
    .name  .attr
    soup本身.name 为 document
    soup.name| soup.head.name
    soup.p.attrs |soup.p['class']| soup.p.get('class') |soup.p['class']="newClass" 
- NavigableString
    soup.p.string 子节点只有一个标签|子节点有多个标签
- BeautifulSoup
    特殊的 Tag  
- Comment
    特殊的 NavigableString 对象，标签内部为注解时：
    soup.a.string 取值没有注解，类型为 type(soup.a.string)==bs4.element.Comment
```

解析格式：lxml|lxml-xml|xml|html5lib|html.parser
- html.parser 标准库
- html5lib 纯 Python 实现
	BeautifulSoup(markup, “html5lib”)
- lxml HTML 解析器
	BeautifulSoup(markup, “lxml”)
	a. 速度快
	b. 文档容错能力强
	c. 文档容错能力强/需要安装 C 语言库
- lxml XML 解析器
	BeautifulSoup(markup, [“lxml”, “xml”])BeautifulSoup(markup, “xml”)
	a. 唯一支持 XML 的解析器
	b. 需要安装 C 语言库

## 2.1 find_all
``` 
find_all( name , attrs , recursive , text , **kwargs )  
    1. 传字符串 最简单的过滤器是字符串 find_all('a')
    2. 传正则表达式 find_all(re.compile("^b")) 以b开头的标签
    3. soup.find_all(["a", "b"])
    4. 传入一个方法，(tag)=>bool.

    attrs={"data-foo": "value"}
    text="Elsie"

    kwargs 参数：
    id='l123',class_="sister",href=re.compile("elsie"),text="Elsie"
    limit=2: 返回结果限制
    recursive=True : 检索当前 tag 的所有子孙节点 :false 子节点
```
