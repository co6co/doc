# 1. `exec()` 函数：
`exec()` 是用来执行动态Python代码的主要函数。它可以接受一个字符串参数，该字符串包含你想要执行的Python代码。例如：
```
code = "print('Hello, World!')"
exec(code)
```
或者，你也可以传递一个包含代码的文件对象：
```
with open('my_code.py') as f:
    exec(f.read())
```
## 1.1 使用`exec`与`globals() `和` locals()`：
当你在函数或类的方法中使用exec时，可以传递`globals() `和` locals() `字典作为命名空间，以便代码可以访问当前作用域中的变量。例如：
```
def my_function():
    x = 5
    code = "print(x * 2)"
    exec(code, globals(), locals())
```
这样，**code 中的 x 将引用 my_function 中的 x 变量**。
# 2. `eval()` 函数：
`eval()` 函数与`exec()` 类似，但主要用于**计算表达式的值**。它**返回计算结果**，而不是执行语句。例如：
```
expression = "3 + 5"
result = eval(expression)
print(result)  # 输出: 8
```
注意：eval() 可能存在安全风险，因为它可以执行任意的Python代码。在处理不受信任的输入时应谨慎使用。

# 3. `compile()` 函数：
如果你想要**更细粒度**地控制代码的执行，可以使用`compile()`函数将**源代码编译成字节码**，然后再执行。例如：
```
source = "x = 5\ny = 10\nx + y"
code = compile(source, '<string>', 'exec')
exec(code)
```
或者，如果你想直接得到表达式的计算结果：
```
expr = "5 + 10"
code = compile(expr, '<string>', 'eval')
result = eval(code)
print(result)  # 输出: 15
```
# 注意
动态执行代码的能力非常强大，但也可能引入安全风险，特别是在处理来自不可信来源的代码时。因此，在使用`exec()`、`eval()`等函数时，一定要确保代码的来源是可靠的，避免执行恶意代码。


```
import sys
import subprocess
import importlib

def install(package):
    subprocess.check_call([sys.executable, "-m", "pip", "install", package])

def ensure_module_installed(module_name):
    try:
        importlib.import_module(module_name)
    except ImportError:
        print(f"{module_name} 模块未找到，正在尝试安装...")
        install(module_name)

# 假设你想确保 numpy 包已经被安装
ensure_module_installed("numpy")
```
