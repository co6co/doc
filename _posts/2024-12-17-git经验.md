# 1. 撤销本地仓库提交 
因本地有很多临时大文件一不小心做了 `git commit`,可以使用 `git reset --soft 1642706cd0d7f35a63e41c757106bda4ce71c2c5` 来撤销提交

**reset之后的几个参数：**

a. --mixed：表示`不删除`工作空间改动过的代码，`撤销commit`，并且`撤销git add . `操作，这个为默认参数（git reset --mixed HEAD^和git reset HEAD^操作效果一样）
b. --soft：表示`不删除`工作空间代码，`撤销commit`，`保留git add .`操作
c. --hard：表示`删除`工作空间代码，`撤销commit`，`撤销git add .`操作，在完成这个操作之后恢复到上一次commit的状态（即有改动的代码没了）
