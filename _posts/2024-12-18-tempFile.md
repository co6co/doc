# 1. 获取临时文件夹路径
```
tmp=tempfile.gettempdir()
# C:\Users\<用户名>\AppData\Local\Temp
# /tmp
```

# 2. 创建临时文件.(**关闭后自动删除**)
```
# 创建一个临时文件
with tempfile.TemporaryFile(mode='w+') as temp:
    temp.write("Hello, World!")
    temp.seek(0)  # 移动文件指针到开头
    content = temp.read()
    print(f"Content of the temporary file: {content}")

# 文件在退出 with 语句块后自动删除
```

## 2.1 创建命名的临时文件
你可以通过 name 属性获取文件的路径。如果 `delete=False`，文件在关闭后不会自动删除。
```
# 创建一个命名的临时文件
with tempfile.NamedTemporaryFile(mode='w+', delete=False) as temp:
    temp.write("Hello, World!")
    temp_path = temp.name

print(f"Path to the temporary file: {temp_path}")

# 手动删除文件（如果需要）
import os
os.remove(temp_path)
```

# 3. 创建临时目录
`tempfile.TemporaryDirectory()` 函数创建一个临时目录，
并返回一个 `TemporaryDirectory` 对象。该目录在退出 with 语句块后会自动删除。

##　3.1 `tempfile.mkdtemp()`
创建一个临时目录，并返回目录的路径。与 TemporaryDirectory 不同，mkdtemp 创建的目录不会自动删除，你需要手动删除它。

# 4. 前缀、后缀和位置
```
#创建一个命名的临时文件，带有自定义前缀和后缀
tempfile.NamedTemporaryFile(prefix="my_prefix_", suffix=".txt", delete=False)
# 创建一个临时目录，带有自定义前缀
temp_dir = tempfile.mkdtemp(prefix="my_temp_")


```

# 5. 临时文件[夹]位置
```
#创建一个临时文件，存储在指定目录中
tempfile.NamedTemporaryFile(dir='/path/to/custom/dir', delete=False)
## 创建一个临时目录，存储在指定目录中
temp_dir = tempfile.mkdtemp(dir='/path/to/custom/dir')
```
