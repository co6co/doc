# 密码文件

## a. 手势密码
九个点的数据含义，含义是这样的：
从左上角起编号为 00，至右下角止编号为 08。那么“闪电”的编码应该是01030406。
使用`SHA1算法`对上述十六进制编码进行计算后得到密文“F2A5B79ECD8B5428F474355287BE6ED857E73208”
```
adb shell到设备上
adb pull /data/system/gesture.key # 下载到本地
rm  /data/system/gesture.key	  # 删除密码文件 	
``` 

## b. 键盘密码
4-16位字符密码[94个字符，包括52个大小写英文字母+10个数字+30个除空格外的标点符号]
加入salt后进行SHA1和MD5散列值计算,暴力破解基本不可能
```
rm  /data/system/password.key
```

# adb 一些命令
需要允许USB调试模式弹出框
## a. 重启adb
输入命令：`adb devices`。显示`unauthorized `,可以重启adb server或者重新获取授权
```
# 重启
adb kill-server
adb start-server 
adb shell

#以尝试重新授权
cd /Users/用户名/.android/
rm adbkey adb_usb.ini
```

# fastboot
```
fastboot devices #列出所有通过 USB 连接并且处于 fastboot 模式的设备。
fastboot reboot #重启设备进入正常模式。
fastboot reboot-bootloader #重启设备进入 bootloader 模式（即 fastboot 模式）。
fastboot flash [partition] [filename] #将指定文件刷写到设备的特定分区。例如：
fastboot flash boot boot.img #- 刷写新的引导镜像。
fastboot flash system system.img #- 刷写系统分区。
fastboot flash recovery recovery.img #- 刷写恢复镜像。
fastboot erase [partition] #擦除指定分区。例如：fastboot erase system 会擦除系统分区的所有数据。
fastboot oem unlock #解锁设备的引导加载程序。这通常会导致设备上的所有用户数据被清除，并且可能会使设备失去保修资格。
fastboot oem lock #锁定设备的引导加载程序。锁定后，你将无法再刷写自定义镜像或解锁引导加载程序，除非再次解锁。
fastboot getvar [variable] #获取设备的变量信息 
fastboot getvar all - 获取所有可用的变量信息。
fastboot getvar version - 获取 fastboot 协议版本。
fastboot continue #在某些情况下，如果设备在 fastboot 模式中挂起，可以使用此命令让设备继续启动过程。
fastboot set_active [a|b] #对于支持 A/B 分区的设备，设置当前活动的系统分区为 A 或 B。这对于无缝更新非常重要。
fastboot --set-active=[a|b] #另一种方式来设置活动分区，适用于较新的 Android 版本。
fastboot flashing [unlock|lock] #有些设备可能需要使用 flashing unlock 或 flashing lock 来代替 oem unlock 和 oem lock。
fastboot flash:raw [command] #用于执行原始分区的刷写操作，这个命令在较老的设备上更为常见。
fastboot update [filename] #使用完整的 OTA 包或官方固件包更新设备。
```

## 1. 刷入 recovery
```
.\fastboot flash recovery twrp-3.4.0-0-davinci.img
```
## 2. 如果不希望安装 TWRP，而只是临时使用 TWRP，运行下面命令（自行替换文件名）并忽略第 3 步骤。
```
.\fastboot boot twrp-3.4.0-0-davinci.img
```
3. 为防止重启手机 MIUI 自动替换回官方 Recovery，按住手机音量上键，同时电脑运行下面命令重启手机，直至进入 TWRP 界面。

.\fastboot reboot
4. 在进入 TWRP 后，会询问“是否保持系统分区为只读”。这里滑动按钮以允许修改 ，不然不能禁止 MIUI 替换回官方 Recovery。
由于 MIUI 在启动时会检查 System 分区完整性，上一步 TWRP 修改了 System 分区，这时重启手机会无法启动系统（“卡米”问题），需要通过刷入 Magisk 移除启动验证，步骤如下。
电脑下载 Magisk 安装包，将其复制到手机上（这时电脑可以识别手机 MTP 设备）；
TWRP 界面上点击“安装”，找到下载的是 Magisk 安装包，点击文件名，滑动按钮刷入；
等待 Magisk 刷入完成，点击“重启系统”，这时就不会有“卡米”问题，重启手机也不会丢失 TWRP 安装；
