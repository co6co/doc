# 切换到命令行 
默认情况下，Ctrl+Alt+F1对应第一个命令行界面，Ctrl+Alt+F2对应第二个命令行界面，依此类推。 
按下相应的快捷键后，屏幕会切换到命令行界面。 要切换回图形界面，可以按下Ctrl+Alt+F7或Ctrl+Alt+F8

# 网卡
```
ifconfig eth0 up # 启动网卡 down 关闭网卡
ifconfig -a # 查看所有网卡
dhclient eth0 # dhcp 客户端分配IP


//
auto eth0
// 
iface eth0 inet dhcp
//
iface eth0 inet static
address 192.168.1.100
netmask 255.255.255.0
gateway 192.168.1.1


```

# 升级
```
sudo apt-get update # 通过apt命令更新软件包列表
sudo apt-get upgrade # 升级已安装的软件包
sudo apt-get dist-upgrade # 升级内核

#下面命令更新整个Kali Linux发行版，包括系统内核、系统库和应用程序。
sudo apt-get update
sudo apt-get dist-upgrade
sudo apt-get clean
sudo apt-get autoremove

#升级过程中遇到依赖关系错误，请尝试使用以下命令修复
sudo apt-get -f install

 sudo apt full-upgrade #下命令来完全升级系统，包括升级内核和其他系统文件
 sudo apt update && sudo apt -y full-upgrade
```
