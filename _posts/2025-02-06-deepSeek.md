# 0. 简介
部署 DeepSeek 本地模型，并通过 Ollama 提供 API 支持，Chatbox 提供 UI 界面。
- 下载Ollama并安装运行DeepSeek
- 下载Chatbox并配置为本地DeepSeek
- 无需联网也能和DeepSeek畅快聊天

# 1. 下载Ollama
[https://ollama.com/](https://ollama.com/)

根据自己硬件配置选择适合的 `deepseek-r1` 模型大小,应该至少有 8 GB 可用 RAM 来运行 7 B 型号，16 GB 来运行 13 B 型号，32 GB 来运行 33 B 型号。

# 2. 运行
```
ollama run `deepseek-r1:1.5b` # 可替换为其他模型
# 直接可以和DeepSeek对话
```
## 2.2 远程服务
```
// win
#点击编辑你账户的环境变量。
#为你的用户账户编辑或创建新的变量 OLLAMA_HOST，值为 0.0.0.0； 为你的用户账户编辑或创建新的变量 OLLAMA_ORIGINS，值为 *。
OLLAMA_HOST=0.0.0.0
OLLAMA_ORIGINS=*

//mac
launchctl setenv OLLAMA_HOST "0.0.0.0"
launchctl setenv OLLAMA_ORIGINS "*"

//linux
[Service]
Environment="OLLAMA_HOST=0.0.0.0"
Environment="OLLAMA_ORIGINS=*"
```

## 2.3 更改模型放置位置
默认情况
- Windows : `C:\Users\%username%\.ollama\models`
- MacOS : `~/.ollama/models`
- Linux : `/usr/share/ollama/.ollama/models`
```
//win
添加 OLLAMA_MODELS 环境变量，例如 OLLAMA_MODELS=E:\.models 
//linux
[Service]
Environment="OLLAMA_MODELS=/home/<username>/ollama_models"
```


# 3. 下载Chatbox并配置为本地DeepSeek
[chatboxai](https://chatboxai.app/en)

选择**`OLLAMA API`**，然后就可以看到我们上一步安装好的`deepseek-r1:1.5b`

# 4. Ollama 加载GGUF模型文件

[GGUF模型1](https://huggingface.co/TheBloke)
[无内容审核大模型](https://huggingface.co/TheBloke/CausalLM-14B-GGUF)

## 4.1　创建模型配置文件
下载好gguf文件后，再自己创建一个`Modelfile`文件【文件名自建】，文件内容写一句话即可，主要为表示gguf模型文件的路径，路径根据自己的实际情况写。
```
FROM ./causallm_7b.Q5_K_S.gguf
```
这里的FROM参数用于指定需要加载的具体模型文件。
## 4.2 构建对应的Ollama模型
```
cd "Modelfile 文件所在路径"
#7bQ5 是我们准备在Ollama中使用该模型的别名,参数解释如下: ollama create choose-a-model-name -f <location of the file e.g. ./Modelfile>
>ollama create 7bQ5 -f ./Modelfile
//显示
gathering model components
copying file sha256:954755087baa037c7c70beb7320b7cd5c1a181aab22e8286881e9f8ff1abc784 100%
parsing GGUF
using existing layer sha256:954755087baa037c7c70beb7320b7cd5c1a181aab22e8286881e9f8ff1abc784
writing manifest
success

```
## 4.3 使用模型
```
ollama run c7b "请写一个幽默笑话"
```

# 5. 命令
```
ollama list # 查看存在的模型
ollama rm <model_name> #删除模型
ollama show --modelfile gemma:2b #打印任何本地模型的 Modelfile
# from 命令使用的几种方式
FROM <model name>:<tag>
FROM llama2
FROM ./ollama-model.bin

```
