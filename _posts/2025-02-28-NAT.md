# NAT 类型及其特点

NAT（Network Address Translation，网络地址转换）是一种用于在私有网络和公共互联网之间进行地址映射的技术。根据 NAT 的实现方式和行为特性，通常可以将 NAT 分为以下几种类型：

## 1. Full Cone NAT（完全锥形 NAT）
![Full Cone NAT]({{ "/static/安全/img/nat/NAT01.png" | prepend: site.baseurl }})
- **特点**：
  - 如果一个内部设备通过 NAT 发起对外部的连接，NAT 会为该设备**分配一个外部 IP** 和端口。
  - 任何外部主机都可以通过这个外部 IP 和端口与该内部设备通信，而无需内部设备事先向该外部主机发送数据包。
- **适用场景**：
  - 这是最宽松的 NAT 类型，适用于需要直接从外部访问内部设备的场景。
- **优点**：
  - 最容易穿透，适合 P2P 应用。
- **缺点**：
  - 安全性较低，因为外部主机可以直接连接到内部设备。

## 2. Restricted Cone NAT（受限锥形 NAT）
![Full Cone NAT]({{ "/static/安全/img/nat/NAT02.png" | prepend: site.baseurl }})
- **特点**：
  - 如果一个内部设备通过 NAT 向某个外部主机发送数据包，则只有该外部主机可以通过 NAT 分配的外部 IP 和端口与内部设备通信。
  - 其他未被内部设备联系过的外部主机无法直接访问内部设备。
- **适用场景**：
  - 常见于家庭路由器中，提供一定的安全性，同时允许 P2P 应用正常工作。
- **优点**：
  - 比 Full Cone NAT 更安全。
- **缺点**：
  - 需要内部设备先发起连接才能建立通信。

## 3. Port-Restricted Cone NAT（端口受限锥形 NAT）
![Full Cone NAT]({{ "/static/安全/img/nat/NAT03.png" | prepend: site.baseurl }})
- **特点**：
  - 与 Restricted Cone NAT 类似，但更严格。
  - 内部设备向某个外部主机的特定端口发送数据包后，只有来自该外部主机的相同端口的数据包才能通过 NAT 与内部设备通信。
- **适用场景**：
  - 更加安全，适合需要限制外部访问的应用。
- **优点**：
  - 提供更高的安全性。
- **缺点**：
  - 对 P2P 应用的支持不如前两种 NAT 类型。

## 4. Symmetric NAT（对称 NAT）
![Full Cone NAT]({{ "/static/安全/img/nat/NAT04.png" | prepend: site.baseurl }})
- **特点**：
  - 每次内部设备向不同的外部主机或端口发送数据包时，NAT 都会为其分配一个新的外部 IP 和端口。
  - 因此，外部主机无法预测 NAT 的映射规则，必须依赖内部设备先发起连接。
- **适用场景**：
  - 常见于企业网络中，提供最高的安全性。
- **优点**：
  - 最安全的 NAT 类型。
- **缺点**：
  - 对 P2P 应用支持较差，通常需要额外的中继服务器或 STUN/TURN 协议来辅助通信。

---

## NAT 类型总结对比

| 类型                  | 外部主机能否主动连接内部设备 | 安全性 | P2P 支持 |
|-----------------------|-------------------------------|--------|----------|
| Full Cone NAT         | 是                            | 低     | 最好     |
| Restricted Cone NAT   | 只能是之前联系过的主机        | 中等   | 较好     |
| Port-Restricted Cone NAT | 只能是之前联系过的主机和端口 | 高     | 一般     |
| Symmetric NAT         | 不可能（需特殊机制）          | 最高   | 最差     |

## 如何检测 NAT 类型？
检测 NAT 类型通常需要借助工具或服务，例如：
- **STUN（Session Traversal Utilities for NAT）**：一种协议，用于帮助客户端确定其公共 IP 地址和 NAT 类型。
- **第三方工具**：如 `nattype`、`stunclient` 等。
- **在线服务**：一些网站提供免费的 NAT 类型检测功能。

## NAT 映射中的 Internet 端口
当 NAT 为本地端口绑定一个 Internet 端口时，以下是常见的行为：
1. **端口重映射**：
   - 如果多个内部设备使用相同的本地端口访问外部网络，NAT 会为每个设备分配不同的外部端口。
2. **端口保留**：
   - 某些 NAT 实现可能会保留外部端口映射一段时间，即使内部设备停止使用该端口。
3. **动态分配**：
   - 在 Symmetric NAT 中，每次连接都会动态分配新的外部端口。
