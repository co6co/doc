# 1. 背景

```
1. *arg 必须放在所有位置参数和默认参数之后
2. **kwargs 必须放在最后
3. *arg 要放在 **kwargs 之前

[仅限位置参数] / [位置或关键字参数] [* 或 *args] [仅限关键字参数] [**kwargs]
1. /：左侧的参数只能通过位置传递（不能用关键字），右侧的参数可以用位置或关键字传递。
2. *：作为分隔符时，右侧的参数必须通过关键字传递（仅限关键字参数）。
3. *args：收集所有额外的位置参数（替代*作为分隔符的功能，且能收集参数）。
4. **kwargs：收集所有额外的关键字参数（必须放在最后）。

def func(a, b, /, c, d, *args, e, f, **kwargs):
	pass
def func(a, b, /, c, d, *, e, f, **kwargs):
	pass


关键字参数（keyword-only）,设置默认值的方式与普通参数相同，直接在参数后用 = 赋值即可

def func(*args, keyword1=10, keyword2="default"):
	pass
## 普通参数 → 带默认值的普通参数 → *args → 带默认值的关键字参数
def func(a, b=5, *args, c=10, d="hello"):
	pass


```

## 合法不合理的定义[不推荐该定义]

```
# 错误1：带默认值的关键字参数放在*args之前
def func(a, c=10, *args):
    pass  # 这里的c是普通参数（非keyword-only），允许但不推荐这样设计

# 错误2：关键字参数不带默认值且调用时未传参
def func(*args, c):  # c是keyword-only参数，无默认值
    pass

func(1, 2)  # 报错：缺少关键字参数c（必须传）

```
