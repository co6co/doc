# 1. 音频转换

```
ffmpeg -i input.m4a -c:v copy -c:a libmp3lame -q:a 4 output.mp3 # 可以使用-vn  代替 -c:vn copy
```

# 2. 分割音频

```
//每5分钟分割一个音频
ffmpeg -i input.mp3 -f segment -segment_time 300 -c copy output_%03d.mp3
//指定时间
ffmpeg -i input.mp3 -ss 00:00:00 -to 00:04:00 -c copy output_01.mp3"
# 示例：将音频从第10秒开始切割，持续20秒
ffmpeg -i input.mp3 -ss 00:00:10 -t 00:00:20 -c copy output.mp3

# 合并文件
ffmpeg -f concat -safe 0 -i list.txt -c copy -bsf:a aac_adtstoasc -movflags +faststart out.mp4
# list.txt < 'file D:\stp下7ef2eb2a5fe3c19b71ad.ts ...'
```

# 3. 剪接视频

## 3.1 分步骤

```
# 1. 截取头部（从 00:00:00 开始，截取 15 秒）
ffmpeg -i input.mp4 -to 00:00:15 -c copy part1.mp4

# 2. 截取尾部（从 00:00:45 开始，截取到视频结束）
ffmpeg -i input.mp4 -ss 00:00:45 -c copy part2.mp4

//list.txt
file 'part1.mp4'
file 'part2.mp4'

#3. 合并
ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4
```

## 3.2 一步

需要重新编码视频（命令中用了 -c:v libx264），处理时间会比较长，且如果时间点没对准关键帧，衔接处依然可能有轻微卡顿

```
#
ffmpeg -i input.mp4 -filter_complex "[0:v]trim=end=00:00:15[v1];[0:v]trim=start=00:00:45[v2];[v1][v2]concat=n=2[vout]" -map "[vout]" -c:v libx264 -crf 18 -preset fast output.mp4

说明：
trim=end=00:00:15：保留前15秒。
trim=start=00:00:45：保留45秒以后的内容。
concat=n=2：将这两段视频流连接起来。

```

# 4 关键帧

I 帧（Intra-coded Picture）：也叫关键帧。它是独立完整的画面，就像一张完整的 JPEG 图片，解码它不需要任何其他帧帮忙。
P 帧（Predictive-coded Picture）：也叫前向预测帧。它不存完整画面，只记录它与前一帧相比“哪里发生了变化”。比如一个人说话，背景不变，P帧就只记录嘴巴的动态。
视频在编码时，为了减少体积，会把一连串的帧打包成一个“组”（GOP）。编码器有一个参数叫 GOP 长度（或者叫 I 帧间隔）
比如说：
第 1 个 I 帧在开头：0.000000秒
第 2 个 I 帧在：12.500000秒
中间整整 12.5 秒，全都是依赖前帧的 P 帧。
GOP 长度被设置成了 12.5 秒（或者 300 帧以上，假设帧率是 24fps 或 25fps）。在这个长达 12.5 秒的 GOP 里，只有首尾是完整的 I 帧，中间的 P 帧全都是“残缺”的

## 4.1 查找关键帧

说明如果关键帧比较少剪接时就会有问题，造成卡顿和跳帧

```
ffprobe -select_streams v -show_frames -show_entries frame=pkt_pts_time,pict_type -of csv input.mp4 | findstr I
```

## 4.2 补齐关键帧

```
# 方法一：指定 GOP 长度（-g 参数，通常和帧率相等即可实现每秒一个关键帧）
ffmpeg -i input.mp4 -g 30 -keyint_min 30 -sc_threshold 0 -c:v libx264 -crf 23 output_fixed.mp4

# 方法二：更暴力的强制关键帧法（确保万无一失）
ffmpeg -i input.mp4 -force_key_frames "expr:gte(t,n_forced*1)" -c:v libx264 -crf 23 output_fixed.mp4
说明：
-g 30表示每隔 30 帧强制一个 I 帧；
-force_key_frames expr:gte(t,n_forced*1)表示每隔 1 秒强制一个 I 帧
-keyint_min 30 用 -g 30来告诉编码器：“最多每隔 30 帧，你必须给我插一个完整的 I 帧（关键帧）。”但有些狡猾的编码器为了缩小体积，即使到了第 30 帧，如果它觉得画面变化不大，可能还会继续往后拖。这时候，-keyint_min 30就是去给编码器立规矩：“不管画面变没变，到了第 30 帧，你必须给我强行塞一个 I 帧！”
它和 -g 30（最大间隔）搭配使用，就能把关键帧的间距死死锁在 固定的 30 帧（通常是 1 秒，如果视频是 30fps 的话）

-crf 23 恒定速率因子（Constant Rate Factor），范围是 0-51，数字越小，印得越精细（画质越人好，体积越大），默认值是 23[画质与体积的黄金平衡点]，类似于 智能的印刷工

```

这个时候随便你怎么下刀剪辑，都不会再出现黑屏或花屏的情况
