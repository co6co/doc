# 音频转换
```
ffmpeg -i input.m4a -c:v copy -c:a libmp3lame -q:a 4 output.mp3 # 可以使用-vn  代替 -c:vn copy
```
# 分割音频 
```
//每5分钟分割一个音频
ffmpeg -i input.mp3 -f segment -segment_time 300 -c copy output_%03d.mp3
//指定时间
ffmpeg -i input.mp3 -ss 00:00:00 -to 00:04:00 -c copy output_01.mp3"
# 示例：将音频从第10秒开始切割，持续20秒
ffmpeg -i input.mp3 -ss 00:00:10 -t 00:00:20 -c copy output.mp3
```
