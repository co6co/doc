# 1. 处理 Base64 编码和解码主要有两套不同的API

## 1.1 传统 Web API：`btoa()`和 `atob()`

- btoa()​ - Binary to ASCII
  > 将二进制数据（实际上是字符串）编码为 Base64
  > 只能处理 ASCII 字符，对于非 ASCII 字符会报错
  > 使用方式：btoa("Hello")
- atob()​ - ASCII to Binary
  > 将 Base64 字符串解码为原始字符串
  > 使用方式：atob("SGVsbG8=")

```
const encoded = btoa("Hello World");  // "SGVsbG8gV29ybGQ="
const decoded = atob("SGVsbG8gV29ybGQ=");  // "Hello World"
```

注意： 无法直接处理包含非 ASCII 字符（如中文）的字符串，需要先进行 UTF-8 编码

## 1.2 现代 API：TextEncoder和 TextDecoder

> `.encode()`​ 和 `.decode()`​ 结合 Base64 转换

```
// 处理包含非 ASCII 字符的字符串
function encodeBase64(str) {
    const encoder = new TextEncoder();
    const data = encoder.encode(str);
    return btoa(String.fromCharCode(...data));
}

function decodeBase64(base64) {
    const binary = atob(base64);
    const bytes = new Uint8Array(binary.length);
    for (let i = 0; i < binary.length; i++) {
        bytes[i] = binary.charCodeAt(i);
    }
    const decoder = new TextDecoder();
    return decoder.decode(bytes);
}
```

# 2. 比较

原生 atob和 btoa是一个功能不完整、存在兼容性问题的“简陋”工具。而像 [js-base64](https://www.npmjs.com/package/js-base64)这样的专门库，是一个功能完整、处理了各种边界情况、跨平台.
