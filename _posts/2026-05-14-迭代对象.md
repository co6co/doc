# 1. 可迭代对象iterable,迭代器 Iterator

- 可迭代对象Iterable `__iter__`
  ```
  #from collections.abc import Iterator,Iterable
  from typing import Iterable,Iterator  # 给上面取了个别名
  nums=[1,2,3]
  isinstance(nums, Iterable)
  isinstance(nums, Iterator)  # Flase
  ```
- 迭代器 Iterator`__iter__+ __next__`

  ```
  it = iter([1,2,3])
  isinstance(nums, Iterable) # True
  isinstance(it, Iterator)
  ```

```
class MyIterator:
    def __init__(self, data):
        self.data = data
        self.index = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.index >= len(self.data):
            raise StopIteration
        val = self.data[self.index]
        self.index += 1
        return val
```

```
nums=[1,2,3,4]
for x in nums:
    print(x)
#########等价于###########
it = iter(nums)
while True:
    try:
        x = next(it)
        print(x)
    except StopIteration:
        break
```

# 2. 生成器

是边遍历边算的设计，
是一种特殊的迭代器, 使用`yield`或生成器表达式创建，其特点：

- 惰性计算（用到才生成）
- 一次性 (不可重复使用)
- 节省内存

```
def count():
    print("start")
    yield 1
    print("middle")
    yield 2

g = count() # 不会执行函数体
 next(g)    # 每次 next()→ 执行到下一个 yield
```

## 2.1 生成器表达式

```
(x for x in iterable)
(x for x in range(10) if x % 2 == 0)
("偶数" if x % 2 == 0 else "奇数" for x in range(3))
(x + y for x in range(3) for y in range(3)) #嵌套循环
(x + y for x, y in zip(range(3), range(3))) #同时遍历多个可迭代对象
(f(x) for x in iterable) # 结合函数
sum((x _ 2 for x in range(10))) # 合法
sum(x _ 2 for x in range(10)) # 更推荐
max(x for x in data)
min(x for x in data)
any(x > 0 for x in nums)
all(x > 0 for x in nums)
```

# 3. 一些常见写法

```

def create_gen(x):
    '''创建生成器的方法'''
    return (x for x in range(x))

g=create_gen(3)
for i in g:
    print(i)

# 可以简化为 lambda 表达式
g=lambda x: (i for i in range(x))  # 只是返回生成器
for i in g(3):
    print(i)

# 用完即废，不能重置
g1=g(1)
print(next(g1)) # 0
print(next(g1)) #StopIteration 异常


dict_nums = {x: x*x for x in range(3)}   # dict
set_nums = {x*x for x in range(3)}       # set
print(dict_nums,type(dict_nums))         #{0: 0, 1: 1, 2: 4} <class 'dict'>
print(set_nums,type(set_nums))           #{0, 1, 4} <class 'set'>
```
