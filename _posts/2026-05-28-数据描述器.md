# 1. 数据描述器descriptor

分为：

- 非数据描述器
  只实现 `__get__`
- 数据描述器
  实现 `__get__`和 `__set__`（或 `__delete__`）

注意：
优先级：`Data Descriptor > obj.__dict__ > Non-data Descriptor`

## 1.1 非数据描述(Non-data Descriptor)

仅实现 `__get__​` 可以被实例字典 (`instance.__dict__`) 中的同名属性覆盖。

```
# 1. 访问描述器
print(obj.attr)  # 输出: From Descriptor

# 2. 给实例动态添加一个同名属性
obj.attr = "From Instance Dict"
# 3. 再次访问
print(obj.attr)  # 输出: From Instance Dict (描述器被覆盖了!)
```

## 1.2 数据描述器​ (Data Descriptor)

实现了 `__set__`或 `__delete__`​ (通常也实现 `__get__`),**优先级最高**。无论实例字典中有无同名属性，都会调用描述器的 **get**/**set**

```
# 假设 Descriptor 实现了 __set__
obj = MyClass()

# 1. 访问描述器
print(obj.attr)  # 输出: From Descriptor

# 2. 尝试给实例赋值
obj.attr = "New Value"  # 这里会调用 Descriptor.__set__

# 3. 再次访问
print(obj.attr)  # 输出: From Descriptor (依然由描述器控制)
```

## 1.2.1 `__delete__`方法

`__delete__`方法用于拦截 `del obj.attr`操作。以下是结合你之前 MyClass示例的完整用法：

```
class Desciptor:
    ....
    def __delete__(self, instance):
        print("Deleting value...")
        # 可以在这里做清理工作
        del self._value

# 使用示例
obj = MyClass()

# 设置值
obj.attr = 42
# 输出: Setting value to 42...

# 获取值
print(obj.attr)
# 输出: Getting value...
#       42

# 删除属性
del obj.attr ## 这会触发 __delete__
# 输出: Deleting value...

# 再次访问会出错（因为_value已被删除）
try:
    print(obj.attr)
except AttributeError as e:
    print(f"Error: {e}")
```

## 1.3 相关代码

```
class Descriptor:
    def __get__(self, instance, owner):
        return "From Descriptor"

    # 如果取消下面注释，它就变成了“数据描述器”
    # def __set__(self, instance, value):
    #     pass

class MyClass:
    attr = Descriptor()
```
