# 1. 数据描述器descriptor

分为：

- 非数据描述器
  只实现 `__get__`
- 数据描述器
  实现 `__get__`和 `__set__`（或 `__delete__`）

```
class DataDescriptor:
    def __get__(self, instance, owner): ...
    def __set__(self, instance, value): ...
    def __delete__(self, instance): ...

class NonDataDescriptor:
    def __get__(self, instance, owner): ...

class Test:
    data = DataDescriptor()      # 数据描述器
    non_data = NonDataDescriptor()  # 非数据描述器
```

注意：
优先级：`Data Descriptor > obj.__dict__ > Non-data Descriptor`

## 1.1 非数据描述(Non-data Descriptor)

仅实现 `__get__​` 可以被实例字典 (`instance.__dict__`) 中的同名属性覆盖。

```
# 1. 访问描述器
print(obj.attr)  # 输出: From Descriptor

# 2. 给实例动态添加一个同名属性
obj.attr = "From Instance Dict"
# 3. 再次访问
print(obj.attr)  # 输出: From Instance Dict (描述器被覆盖了!)
```

## 1.2 数据描述器​ (Data Descriptor)

实现了 `__set__`或 `__delete__`​ (通常也实现 `__get__`),**优先级最高**。无论实例字典中有无同名属性，都会调用描述器的 **get**/**set**

```
# 假设 Descriptor 实现了 __set__
obj = MyClass()

# 1. 访问描述器
print(obj.attr)  # 输出: From Descriptor

# 2. 尝试给实例赋值
obj.attr = "New Value"  # 这里会调用 Descriptor.__set__

# 3. 再次访问
print(obj.attr)  # 输出: From Descriptor (依然由描述器控制)
```

## 1.2.1 `__delete__`方法

`__delete__`方法用于拦截 `del obj.attr`操作。以下是结合你之前 MyClass示例的完整用法：

```
class Desciptor:
    ....
    def __delete__(self, instance):
        print("Deleting value...")
        # 可以在这里做清理工作
        del self._value

# 使用示例
obj = MyClass()

# 设置值
obj.attr = 42
# 输出: Setting value to 42...

# 获取值
print(obj.attr)
# 输出: Getting value...
#       42

# 删除属性
del obj.attr ## 这会触发 __delete__
# 输出: Deleting value...

# 再次访问会出错（因为_value已被删除）
try:
    print(obj.attr)
except AttributeError as e:
    print(f"Error: {e}")
```

## 1.3.1 只读数据描述

```
class ReadOnlyProperty:
    def __init__(self, value):
        self.value = value

    def __get__(self, instance, owner):
        return self.value

    def __set__(self, instance, value):
        raise AttributeError("Cannot modify this attribute")

    def __delete__(self, instance):
        raise AttributeError("Cannot delete this attribute")

class Config:
    VERSION = ReadOnlyProperty("1.0.0")

config = Config()
print(config.VERSION)  # 输出: 1.0.0

# 以下都会报错
# config.VERSION = "2.0.0"  # AttributeError
# del config.VERSION        # AttributeError
```

## 1.3.2 缓存失效

```
class CachedProperty:
    def __init__(self, func):
        self.func = func
        self.cache_name = f"_{func.__name__}_cache"

    def __get__(self, instance, owner):
        if instance is None:
            return self
        if hasattr(instance, self.cache_name):
            return getattr(instance, self.cache_name)
        value = self.func(instance)
        setattr(instance, self.cache_name, value)
        return value

    def __delete__(self, instance):
        """清除缓存"""
        if hasattr(instance, self.cache_name):
            delattr(instance, self.cache_name)

class User:
    def __init__(self, id):
        self.id = id

    @CachedProperty
    def profile(self):
        print("Fetching profile from database...")
        return {"id": self.id, "name": "John"}

user = User(1)
print(user.profile)  # 第一次：从数据库获取
print(user.profile)  # 第二次：从缓存获取
del user.profile     # 清除缓存
print(user.profile)  # 再次从数据库获取
```

## 1.3.3 验证删除操作

```
class ProtectedDict:
    def __init__(self, protected_keys):
        self.protected_keys = protected_keys
        self.data = {}

    def __set__(self, instance, value):
        self.data = value

    def __get__(self, instance, owner):
        return self.data

    def __delete__(self, instance):
        # 防止删除整个字典
        raise AttributeError("Cannot delete the entire dictionary")

    def safe_delete(self, key):
        """安全删除特定键"""
        if key in self.protected_keys:
            raise ValueError(f"Key '{key}' is protected")
        del self.data[key]

class Settings:
    config = ProtectedDict(protected_keys={"api_key", "secret"})
    def __init__(self):
        self.config = {"api_key": "123", "theme": "dark"}

settings = Settings()
del settings.config  # 报错：AttributeError
settings.config.safe_delete("theme")  # 成功
```
