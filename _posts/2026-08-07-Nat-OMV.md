# 0. 设置共享需要未使用空间

OMV 默认不让根分区建共享,官方社区插件 openmediavault-sharerootfs，装上后根下任意文件夹就能当共享文件夹用

```
apt update && apt install openmediavault-sharerootfs
装完 Web 界面 → 系统 → 插件，搜 sharerootfs 勾上安装，然后：
根下建个目录：mkdir -p /srv/data（或者直接拿 /home 也行）
存储 → 共享文件夹 → 创建 → 文件系统那里就能选根（/）了，路径指到 /srv/data
SMB/NFS 照常开
```

# 1.2 安装 openmediavault-webdav

插件中搜索 openmediavault-webdav

- 先建共享文件夹（比如叫 webdav-share）
- 给 www-data 用户和 webdav-users 组 rw 权限（ACL 里也要给，不然 403）
- 服务 → WebDAV 启用，共享文件夹选刚建的，用户组选 webdav-users
- 把你的用户加到 webdav-users 组
- 访问地址：http://OMV的IP/

```
可能遇到的问题：
安装 openmediavault-sharerootfs 有线程使用 比如 pid 3100
ps -p 3100 -o pid,cmd
kill 3100          # 先温和
# 几秒后还在就
kill -9 3100
rm /var/cache/apt/archives/lock
dpkg --configure -a
```

# 4. centos 挂载

## 4.1 CentOS 7 安装davfs2

```
sudo yum install -y epel-release
sudo yum install -y davfs2
```

编辑 `/etc/davfs2/davfs2.conf`

```
use_locks 0                  # Nginx WebDAV 不实现 LOCK，必关
ignore_dav_header 1           # Nginx 的 DAV 头不完整
buf_size 16384                # 1.5+ 单位是字节，16384 = 16KiB（1.4.7 时是 128 KiB，别抄错）
dir_refresh 30
file_refresh 10
# 1. secrets 免密

sudo vim /etc/davfs2/secrets
# 末尾加（换成你的 OMV IP / 账号 / 密码）：
http://192.168.1.10/webdav   your_omv_user   your_omv_password

sudo chmod 600 /etc/davfs2/secrets

# 2. fstab
sudo vim /etc/fstab
# 加一行（_netdev 等网络起来再挂，CentOS 7 老 init 也认）：
http://192.168.1.10/webdav   /mnt/omv-webdav   davfs   rw,user,_netdev,uid=$USER,gid=$USER   0   0

# 3. 建挂载点 + 试挂
sudo mkdir -p /mnt/omv-webdav
sudo mount -a
ls /mnt/omv-webdav
可能用到
sudo umount /mnt/omv-webdav
```

# 6. nats-server

## 6.1 复制文件到指定目录，并给权限

```
sudo chmod +x /usr/local/bin/nats-server
```

## 6.2 使用专门用户来跑

```
sudo useradd -r -s /bin/false -d /var/lib/nats -M nats
sudo mkdir -p /var/lib/nats /var/log/nats
sudo chown -R nats:nats /var/lib/nats /var/log/nats
```

## 6.3 最小配置

```
sudo mkdir -p /etc/nats
sudo nano /etc/nats/nats.conf
```

💡 4222 = 客户端口（Python nats-py 连这个），8222 = HTTP 监控（curl localhost:8222/health 能看到状态）。

```
# /etc/nats/nats.conf
listen: "0.0.0.0:4222"
http: "0.0.0.0:8222"


debug: false
trace: false

log_file: "/var/log/nats/nats.log"
log_size_limit: 50MB

# 如果需要用户名密码，把下面打开
# authorization {
#   user: "nats"
#   password: "换一个强密码"
# }
```

## 6.4 配置服务

sudo nano /etc/systemd/system/nats-server.service

```
[Unit]
Description=NATS Server
Documentation=https://docs.nats.io
After=network-online.target

[Service]
Type=simple
User=nats
Group=nats
ExecStart=/usr/local/bin/nats-server -c /etc/nats/nats.conf
ExecReload=/bin/kill -s HUP $MAINPID
Restart=on-failure
RestartSec=5s

# Lame Duck Mode
KillSignal=SIGUSR2
TimeoutStopSec=30

[Install]
WantedBy=multi-user.target
```

## 6.5 开机启动

```
sudo systemctl daemon-reload
sudo systemctl enable --now nats-server
sudo systemctl status nats-server
sudo journalctl -u nats-server.service -f   # 实时跟踪日志

```

## 6.6 测试是否成功

```
nats-server --version
ss -lntp | grep 4222

# HTTP 监控
curl http://localhost:8222/health
# {"status":"ok"}

# 控制台运行
# 方法一
sudo journalctl -u nats-server --no-pager -n 50
# 方法二
sudo -u nats /usr/local/bin/nats-server -c /etc/nats/nats.conf


```

# 7. 其他设置

## 7.1 设置多IP

```
sudo nano /etc/netplan/99-custom.yaml
network:
  version: 2
  ethernets:
    enp2s0:
      addresses:
        - 192.168.3.201/24


# 1. 先 try，120 秒内不确认会自动回滚（远程操作必用！）
sudo netplan try
# 看到 "Do you want to keep these settings? (y/n)" 敲 y

# 2. 确认没问题再永久 apply
sudo netplan apply

# 3. 验证
ip -4 addr show enp2s0
```
